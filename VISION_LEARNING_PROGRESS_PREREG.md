## THE SIGNAL — learning progress as an INTEGER derivative of the residual

The 196000 held surface already computes an INTEGER temporal surprise per held
item: `residual = |obs - held|` (`sd_residual`). Learning progress is its
**backward difference over the innovation clock**:

```
learning_progress(t) := residual_prev  -  residual(t)          [Minus]
```

- `> 0`  — the residual is DROPPING with continued attention ⇒ the item is
  being COMPRESSED ⇒ LEARNABLE-and-progressing (Schmidhuber's dC/dt > 0).
- `≈ 0`  — the residual is FLAT: either RESOLVED (already ~0, nothing left) or
  INTRACTABLE/NOISY (high but nothing gettable). Both read as "no progress."

`residual_prev` is the previous tick's residual, shifted by a terminal
`lp_advance` rule (`residual_prev := residual; epoch := input_epoch`) so the
next tick's difference is well-formed. All integer (`Abs`, `Minus`, `IDiv`,
`Plus` — existing Terms; **term.rs diff EMPTY**).

## THE GATE — decay keyed on progress (NOT on surprise)

Interest is a decaying quantity read with the **exact 196000 atom**
`freshness = Ashr(C0, IDiv(now − last_boost, half_life))` (integer x2^-k,
`scale2` on the epoch axis). Two levers, both driven by the SIGNAL, exactly as
`sd_gate` drives them from the residual — but here from PROGRESS:

- **half-life (how fast interest decays):**
  `interest_half_life = Max(hl_min, hl_min + hl_scale · Max(0, progress))`
  progress high ⇒ LONG half-life (hold); progress ≤ 0 ⇒ `hl_min` (decays fast).
- **clock reset (boost back to C0):** `last_boost_epoch := input_epoch` iff
  `progress > progress_floor` (there IS learning ⇒ sustain interest).
- **interest:** `Ashr(interest_c0, IDiv(input_epoch − last_boost_epoch,
  interest_half_life))`.
- **attend flag (the graph-native allocation decision):** `attended = 1` iff
  `interest ≥ attend_thresh`, else `0`.

Net effect: **HOLD only the surprising-AND-progressing.** Resolved decays
(progress→0), intractable/noisy decays (progress→0), progressing is held.

## THE FALSIFIER — raw-surprise (naive curiosity), `mode = surprise`

Same rules, one knob flipped (`mode = 1.0`): the half-life and clock are keyed
on the **residual (surprise) itself**, not its derivative —
`interest_half_life = Max(hl_min, hl_min + hl_scale · residual)`, boost iff
`residual > surprise_floor`. This is "keep the surprising." A noisy source has
permanently high residual ⇒ half-life stays LONG, clock keeps resetting ⇒
interest STAYS HIGH ⇒ **TRAPPED on the noisy TV** (the classic ICM/prediction-
error failure). Both arms shown side by side.

## THE COMMIT-NET — the order-0 regress-breaker

The marginal value of further deliberation is the SAME diminishing-returns
atom. A `Deliberation` holds a `step` (world clock, incremented per
deliberation tick) and a value with diminishing returns generated by the SAME
`scale2` atom: `value = V_max − Ashr(V_max, step)`, so
`marginal_value = value − value_prev = Ashr(V_max, step)` HALVES each step —
the deliberation's own "learning progress."

The commit is an **order-0 reflex rule** (`cn_commit`, `latency_class:
hard_realtime`) — a single fixed threshold, no search, no recursion: the
meta-decision "decide now or deliberate more?" CANNOT itself be deliberated
(infinite regress), so the net CUTS by fiat.

```
committed := 1   iff   marginal_value < commit_cost   AND   committed == 0
```

This is the order-0 reflex-net philosophy already in the tree (`reflex_net`:
"the fast path IS an ordinary Rule" gated by a TunableParameter) — here the
knob is `commit_cost` and the gate is the marginal-value crossing.

## GATES (pass criteria fixed BEFORE any number)

**G1 — THE NOISY TV (headline).** Two items: LEARNABLE (staged structured
target — residual spikes then drops as `held` converges, recurring positive
progress) and NOISY (white noise — residual permanently high, progress ≈ 0).

- **G1a (gated LEAVES noisy):** gated interest on the noisy item in the late
  window < 0.5 × its early-window peak (interest decays).
- **G1b (gated goes to the LEARNABLE):** in the late window, gated attention
  share (interest / Σ interest) on learnable > share on noisy.
- **G1c (naive TRAPS — the falsifier):** with `mode = surprise`, noisy interest
  in the late window ≥ 0.8 × its early peak (does NOT decay) AND naive late
  attention share on noisy > gated late attention share on noisy.
- **G1 headline:** gated late argmax-of-interest is NOT persistently the noisy
  item; naive late argmax IS persistently the noisy item. Attention-allocation
  curves for both arms are plotted.

**G2 — LEAVE-THE-UNRESOLVED.** Three items: RESOLVED (constant target, learned
early → progress→0, LOW residual), INTRACTABLE (white noise → progress→0, HIGH
residual), PROGRESSING (staged structured → ongoing positive progress).

- **G2a:** interest(resolved) decays (late/early < 0.5).
- **G2b:** interest(intractable) decays (late/early < 0.5).
- **G2c:** interest(progressing) HELD (late ≥ 0.8 × its own sustained level).
- **G2d (the discriminator is PROGRESS, not resolution or surprise-magnitude):**
  resolved has the LOWEST mean residual, intractable the HIGHEST, yet BOTH
  decay while the intermediate-surprise progressing item is held — so the
  retained-interest ranking is NOT the surprise ranking.

**G3 — COMMIT-NET / ANTI-PARALYSIS + CALIBRATION.**

- **G3a (paralysis):** NAIVE arm (`commit_enabled = 0`) — `committed == 0` for
  all H deliberation steps (never terminates within the horizon).
- **G3b (calibrated commit terminates and acts):** calibrated `commit_cost`
  fires `committed = 1` at step `k*` with `0 < k* < H`, at the marginal-value =
  cost crossing, and `k*` matches the analytic `Ashr(V_max, step) < commit_cost`
  prediction exactly (integer).
- **G3c (impulsivity):** too-aggressive `commit_cost` (≥ the first marginal)
  fires at step ≤ 1 — commits before progress (premature).
- **G3d (passivity = paralysis):** `commit_cost = 0` never fires within H.
- **G3 headline:** termination step vs the marginal/cost curves plotted for the
  paralysis / impulsive / calibrated arms; the calibrated cut sits at the
  crossing.
