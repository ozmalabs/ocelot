# P2-B1 preregistration — bounded native counterfactual planning

**Status: pre-release native scaffolding only; no score is published or claimed.** The checked-in lock remains intentionally invalid until the real release build has passed the native worker/evaluator, receipt-restart, hardened-Podman, and held-out clone test gates. Pre-release code may exercise synthetic unit fixtures only; it must not write a results receipt, treat a fixture lock as a release lock, or advertise capability evidence. Release activation requires independently produced non-placeholder image, binary, rule, seed, vocabulary, split-commitment, seccomp, and signing-key values, followed by publication of the canonical lock hash before the first scored episode. A missing or changed lock invalidates the run.

## Claim and fixed boundary
P2-B1 establishes only a finite one-action (`H=1`) native graph plan. Every envelope permits at most four root actions, branching `B=1`, and at most eight nodes per action. The worker reconstructs a fresh `WorldModelObservation`/`BeliefState`, creates action-conditioned `WorldModelAction`, `SimulationRequest`, `PredictionTrajectory`, and `PredictedBeliefState` graph objects, then adapts those records into the declared Rust `select_all_actions` bounded future-manifold path (`P2BoundedFutureManifoldV1`). The exported selection carries its feasible/minimal/tie sets as direct derivation proof; no parallel JSON-local comparator may select an action. It either proposes one safe goal-satisfying minimum-intervention action from its submitted prediction set, preserves equal minima for sealed enactment rank, or abstains. It makes no claim about open-ended discovery, arbitrary causal calculus, or multi-action planning.

Per episode: 2 CPU seconds, 3 wall seconds, 512 MiB, 32 PIDs, 64 KiB framed stdout, zero network bytes, and no state persistence. The lexicographic objective is native support/resolved manifold audit; safety and authorized effort; all public goals above confidence threshold; least represented intervention; then highest declared goal probability. Equal minima remain a native tie set. The evaluator's sealed enactment rank may choose a tied member but never ranks by input order or opaque spelling.

## Custody and sequence
A fresh rootless Podman container gets only an evaluator-signed canonical `P2ObservationEnvelopeV1`: opaque identifiers, public observations, legal actions, public goals/cost bounds, fixed budget, and public training bundle. It gets neither authoritative state, hidden mechanisms/parameters, paths, sockets, callbacks, capabilities, action grants, simulator interface, or hidden tables. The digest-pinned image has a fixed `/runtime/p2_native_worker` native entrypoint, read-only root and `/agent`/`/input`, empty `/work` tmpfs, no network, no inherited environment, dropped capabilities, no-new-privileges, seccomp, non-root UID/GID, PID/CPU/memory limits, no host/container socket, and no writable host mount. There is no Bubblewrap/local fallback and no Python runtime or planner in the worker. A separate digest-pinned Python runtime exists only in the hostile-probe image; it receives the exact same Podman policy and never participates in planning.

For each legal action the worker submits exactly one bounded counterfactual record: source-belief and transition-witness digests; graph export; outcome distribution in integer basis points summing to 10,000; predicted goals/cost; support/resolved/loss/information-loss/decisive-tick manifold fields; confidence/uncertainty; terminal status. Missing/duplicate/nonlegal/malformed/unsupported/unresolved predictions are classified only as `unestablished`, `infeasible`, `budget_exhausted`, or `protocol_error`; they are never silently completed.

The separate evaluator-native process rebuilds a fresh graph from the public bundle, signed envelope, and untrusted export; replays bounded rules; validates witnesses/provenance; recomputes projection/selection; and validates selected/minimal/tie claims. Only accepted proposals reach broker mediation. Rejection defaults to `protocol_error`, zero success credit, and no world mutation. The evaluator then runs non-mutating authoritative clones for every legal action and at most one enacted legal action. Receipts never disclose hidden state. Before any plan request, the evaluator sends the sole fixed `P2NativeRuntimeProbeV1`; the worker may return only the versioned ready response or fixed context-safe failure codes (`input_frame_invalid`, `request_schema_invalid`, `sealed_digest_mismatch`, `sealed_graph_invalid`, `bounded_simulation_failed`, `output_write_failed`, or `unknown_native_failure`). OCI launch outcomes are recorded only as fixed evaluator reason codes; no loader paths, stderr, IDs, mounts, or request fragments are disclosed.

The release context is generated locally from a measured `P2NativeRuntimeClosureV1`: the worker digest, ELF class/machine, interpreter destination, and every resolved `DT_NEEDED` runtime file/digest. The closure artifact is lock-bound and the fixed runtime probe must succeed in the digest-pinned scratch image before scoring. This does not add a shell, Python, package manager, or fallback runtime.

The lock additionally fixes the seccomp-policy digest. Podman rejects a staged policy unless its bytes hash to that lock value, so an arbitrary permissive profile cannot be substituted.

## Split, controls, and gate
The held-out endpoint is generated before execution by the evaluator-owned deterministic `P2HeldOutStudyManifestV1`: its canonical ordered 320-entry index is exactly 4 disjoint composed mechanism families × 8 initial-state strata × 5 opaque-label bijections × 2 independently derived action orders. The manifest locks its index/split commitment and seed commitment; signed envelopes are derived once from the locked evaluator seed and evaluator clone truth remains in a separate private store. The run is incomplete unless every index appears exactly once, all 320 receipt hashes are chained into the independent `P2HeldOutScoringEvidenceV1`, and the raw counts/Wilson intervals are retained. Training has singleton families; held-out families/compositions are disjoint. Secret seeds, tables, fixtures, and authoritative state are evaluator-only deployment material.

Mandatory deterministic controls: forged or mismatched sealed digest; stale-transition mismatch; unavailable action; false correlated causal hypothesis; over-budget action; identical-envelope/duplicate-proposal/restart replay; and named in-Podman shell, agent/input write, host-path, network, Unix host-protocol, undeclared-binary, host-callback, and ID-only-route attempts. The separately pinned hostile-Python image also executes valid Python under the identical Podman policy and attempts each of those routes; it emits `executed_no_effect` only for Python runtime execution and `blocked` for every hostile route. The evaluator independently commits `/agent` and `/input` before/after both probes and rejects any mutation. Controls use valid signed envelopes where an envelope is applicable; malformed JSON is not bypass evidence. The release runner executes both separately locked bypass images and refuses scoring if any named attempt is absent, not denied, or has evaluator-side effect evidence. All controls must pass.

Primary gate: sandbox/protocol/reconstruction/safety = 100%; held-out all-action Brier >= .75; held-out feasible-minimal choice >= .70; held-out ECE <= .10; and all controls pass. Wilson 95% intervals and raw signed receipt hashes are required. Any failed/missing check is **P2-B1 not established**, never partial certification.
