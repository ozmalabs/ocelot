# Receipt-bound P5-R0 gate closure

This change closes the P5-R0 readiness gate around signed receipt chains, exact primary/control cardinality, and a five-edge one-factor contrast matrix. It binds terminal, control, contrast, rollback, and close evidence to the run and lock context, rejects synthetic summaries without a verified chain, and keeps local execution explicitly below release readiness. The local smoke completed its raw workload and restored state exactly, while the native path stopped before execution because the trusted closure was unavailable. **Watch for:** **confirmed** native closure is unavailable in this environment, so no native-success claim can be made; the bounded result remains no-go as intended.

**Verdict**: APPROVED

## High-level view

The receipt chain is now the evidence boundary: primary, control, and contrast records must resolve to signed, context-matched receipts, while the locked contrast matrix must be complete, unique, and behaviorally consistent with its declared relation.

Local execution remains a rollback/protocol smoke rather than a promotion path. It produces the raw workload and closure receipts, but no-callback worker reruns are not accepted as verified mechanics evidence, so the disposition remains local-readiness-only/no-go.

Native execution is fail-closed on the absence or mismatch of the trusted authority, immutable image, crun runtime, seccomp profile, and exact closure binding. No local fallback can manufacture native readiness.

### Receipt-bound evidence and attack rejection

The **confirmed** gate closure verifies receipt-chain continuity and signatures, non-null digest links, run and kind context, semantic bindings for primary/control/contrast evidence, uniqueness, exact control ordering, exact contrast coverage, and the final chain digest. Rollback and run-close receipts are required at the end of the chain, with the close receipt bound to the pre-close chain digest.

An independent temporary-root run attempted null receipt, forged receipt, missing pair, duplicate pair, synthetic fallback, and global-only contrast mutations. All six returned `local_readiness_only/no_go`; none could turn the gate into GO. The synthetic and global-only variants were rejected even when summary flags were set optimistically, because the verified receipt-chain object and complete locked contrast evidence are mandatory.

### Local execution and native closure boundary

The **confirmed** local smoke produced 144 primary records, 11 controls, 90 contrast cells, and 337 receipts, then restored the evaluator snapshot exactly. Its no-callback contrast reruns are retained as raw evidence but are not counted as verified mechanics evidence, so local execution cannot cross the native/contrast gate.

The **confirmed** native-no-go path requires the trusted external authority and locked native closure before invoking a worker. With those prerequisites absent, it returns an impasse, preserves the `local_readiness_only/no_go` boundary, and reports exact rollback.

### Validation coverage and remaining execution boundary

Native-adjacent graph/startup/runtime failure tests passed 14 additional tests, and Python compilation plus `git diff --check` passed. **Not tested:** a native-success run through the complete locked crun/Podman closure, because that closure is not present; the no-go behavior is the only valid result available in this environment.
