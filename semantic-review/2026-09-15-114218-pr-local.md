# Deterministic recurrence controls and standing experiment consumers

The change adds deterministic replay coverage for recurrence schedules and broadens the experiment consumer so a grounded self-experiment rule can consume a later induced residual. The replay varies the residual sequence itself—`[p,p,p]`, `[p,∅,∅]`, and `[p,∅,p]`—while holding the threshold and run length fixed, and it confirms that the interrupted sequence mints only on its second appearance. The native-rule test proves that an authored rule can add an `Experiment` and connect the recurrence-minted axis through `tested_by`, but it exercises the Python composer path rather than the changed graph-resident composer seed. **Watch for:** **confirmed** the graph-resident composer has diverged from its Python oracle and its dedicated regression suite currently has 18 failures.  
**Verdict**: NEEDS_CHANGES

## High-level view

Recurrence is now tested as an accumulated episode-wide predicate count rather than inferred from a high threshold or a longer run. The interrupted schedule reaches count two after a gap and mints in segment three, which a consecutive-run implementation would reject; the threshold-99 control is correctly narrowed to boundary coverage.

The standing consumer intentionally removes bootstrap-key and `test`-predicate restrictions so an experiment capability can act on a later residual. The Python-composed authored rule is exercised natively and remains idempotent, but **confirmed** the equivalent graph-resident rule still carries redundant/non-equivalent eligibility predicates, breaking the repository’s graph-versus-Python parity contract.

## Accumulated recurrence is distinguished from consecutive recurrence

`test_accumulated_recurrence_matched_traces` replaces both segment traversal and residual extraction, then runs the production minting loop with the same three-segment horizon and threshold of two for every case. It asserts `[p,∅,p]` produces `residual_persistence == {p: 2}` and invokes the mint gate only in segment 2 (the third segment), while `[p,∅,∅]` never invokes it. The production loop increments a predicate’s ledger only when it appears and never resets absent predicates, so the interrupted assertion is **confirmed** evidence of accumulated rather than consecutive semantics; a consecutive implementation would leave the final run length at one and fail this test.

The relabelled Track 4 and Track 5 claims no longer overstate the threshold-99 run as a recurrence-shape control. Their boundary runs remain useful for threshold enforcement, while the deterministic replay supplies the missing schedule comparison. The duplicate replay also retains the prior over-mint guarantee: an otherwise-due predicate reports the existing axis, produces no new `CapabilityAxis`, and is offered only once.

## The native experiment assertion bypasses the changed graph composer

`test_recurrence_minted_axis_reaches_native_authored_operation` grounds the bootstrap concern through `ground_concern`, then runs the substrate rules after the recurrence axis is minted. It confirms a newly created `Experiment` is reachable from that axis by `tested_by`, has `status == "requested"` and `game == "navigate"`, and a second rule pass creates no duplicate. This is a genuine native authored-rule effect, not a host-created experiment.

The test’s `grounded["path"] == "compose_experiment_rule"` assertion does not establish which composer served the rule, and it never loads `composer_experiment_graph.json`; in contrast, the dedicated graph suite establishes graph routing with `served_by == "graph"`. **Confirmed:** after the seed change, `tests/test_experiment_composer_graph.py` fails 18 of 58 tests. Its first failing parity case compares the `test`-only graph-authored rule to `_compose_experiment_rule`: the Python rule has the `is_axis`, untested, and description checks, while the graph rule now has two `is_axis` checks plus a `Gt(Sum(residual_predicates), 0)` condition. This is not merely a stale expectation—the graph path remains more restrictive for an axis with an empty predicate list and no longer satisfies the project’s stated graph/Python equivalence guarantee.
