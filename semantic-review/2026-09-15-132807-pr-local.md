# Enforced graph-native autonomous discovery

The change implements a preregistered two-segment discovery path whose host adapter supplies only raw facts and a held-out operation; graph rules derive the trajectory, residual evidence, recurrence, mint offer, minted axis, and transfer decision. Boundary instrumentation wraps every public adapter mutation after seed loading, records live phase-tagged telemetry, and makes prohibited derived-node, mint/status, and external-callback use fail immediately. The declared opaque-label bijection is validated as complete and one-to-one, while the scrambled structural control confirms that relabeling does not alter the graph projection or held-out licensing result. The direct root runner successfully generated complete artifacts for all eight cases without `PYTHONPATH`; 14 autonomous tests and four recurrence-ledger tests passed with no skips. Watch for: this environment does not provide an unversioned `python` executable, but the runner is explicitly Python 3 and succeeds with `python3`; this is an environment-wide alias gap, not a task failure.

**Verdict**: APPROVED

## High-level view

The adapter has a narrow, stateful input gate: raw preregistered facts are accepted once, followed by exactly one held-out request. Every public facade mutation after boot is intercepted; permitted writes are recorded from the operation itself, while forbidden writes increment telemetry and raise instead of relying on expected audit literals.

The native closure owns the behavioral chain. `ad_*` rules select the fixed traversal and derive canonical structural residual evidence, `mrl_*` rules aggregate only equal recurrence keys and offer the result to the existing shape-decode authority, and `mrs_*` rules license an operation only when its relation head and roles match a minted witness.

The scramble control separates opaque identities and displays from structural semantics. The fixture requires an exact, injective mapping domain; the active scrambled graph maps its concept, relation, request, entity, and display fields through that mapping, then compares the ordinary and scrambled structural projections and their transfer result.

## Live mutation boundary and callback telemetry

`_AdapterWriteGuard` is installed immediately after the seed closure loads and replaces all public facade mutation entry points. Its phase machine permits only the preregistered raw node/edge vocabulary, locks it after one submission, then permits only an `OperationRequest` and its edge before locking again. Derived discovery/evidence/candidate/observation/axis nodes and all public attribute, type, or deletion operations are rejected; the shared audit object is updated at the attempted operation, so it cannot be a reconstructed success report. The focused tests deliberately attempt every prohibited derived-node type and mint/status mutation, then invoke each raising `ask`, `llm`, `network`, and `tool` stub to establish that both the failure boundary and its counters are live.

## Native trajectory, residual, mint, and transfer chain

The seed connects raw facts to the existing graph-native minting ladder rather than importing the historical Python controllers. The resulting path is:

```text
DiscoveryRequest → DiscoveryEpisode → ThoughtSegment → SegmentSignature
                                              ↓
                                      ResidualStructure → ResidualSegmentEvidence
                                              ↓
                     PredicateRecurrenceCandidate → Observation → CapabilityAxis
                                              ↓
                           ResidualRelationWitness + OperationRequest → license
```

`ad_expand_segment_candidates` and the rank/selection rules choose the next concept from graph edges and traversal order. The residual rule compares the complete five-field canonical tuple against setpoint relations, and the reifier serializes that tuple as the recurrence key; the distinct-structure control therefore produces two persistence-one candidates rather than pooling matching `bind` predicates. `mrl_offer_due_once` gates offers on graph-derived persistence, while the existing `shape_decode_loop` remains the mint authority. `mrs_license_structural_relation` compares only relation head and both roles, which keeps labels and capability keys out of the transfer predicate; role- and head-mismatch controls remain unlicensed.

## Complete opaque-label control

`load_fixture` rejects a missing, extra, empty, or duplicate bijection value against `OPAQUE_LABEL_KEYS`. In the scrambled positive execution, every graph-visible opaque field constructed for that case is obtained through `_label`: concept identifiers and labels, relation names and IDs, training and held-out request values, entity identifiers, and displays. The test proves the mapped values appear in opaque attributes while the source keys do not, and compares the label-erased node/edge projection with the ordinary positive graph. The full fixture domain also declares the mutually exclusive precovered relation and basis labels, preventing an undeclared label from being introduced by another fixed case.
