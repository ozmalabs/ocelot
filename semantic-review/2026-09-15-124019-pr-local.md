# Native recurrence axes feed standing experiment consumers

The experiment composer now authors a standing graph rule rather than binding the rule to the bootstrap concern’s capability key or `test` predicate. A later, recurrence-minted axis is consumed by a graph-authored experiment operation once it is a described `CapabilityAxis`, while an unrelated node that fails `is_axis == 1.0` remains unconsumed. The recurrence adapter posts evidence only; the seed derives persistence, creates the threshold-due observation once, records terminal status, and links a minted axis in graph state. Focused validation passed without skips: 66 pytest cases, both capability tracks, source compilation, seed JSON parsing, and `git diff --check`.

Watch for: **confirmed** the deliberately broader standing consumer remains limited to induced, described `CapabilityAxis` nodes and is protected from duplicate consumption by `tested_by`.

**Verdict**: APPROVED

## High-level view

The composer no longer treats its bootstrap key or predicate set as an eligibility boundary. Its authored rule is a persistent consumer for a subsequent unexplained, induced axis: a non-axis observation creates neither an experiment nor a `tested_by` edge; a later differently keyed qualifying axis creates exactly one experiment and is stable on replay.

The Python minting loop is now the trajectory/evidence adapter. Graph-native rules own candidate identity, accumulated count, readiness, one-time offer, decoding outcome, and the episode/candidate-to-axis provenance needed by downstream consumers. The graph seed and the read-only Python composer oracle use the same relaxed eligibility rule, which the structural-equivalence regression checks.
