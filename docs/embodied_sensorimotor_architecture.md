# Embodied sensorimotor architecture

## Outcome

The ground, aerial, and humanoid controllers now share one graph-native
sensorimotor layer. It does not identify a body as a car, drone, or person.
It learns from opaque effectors, delayed physical receipts, and uncertain
multimodal observations.

The simulator boundary only transduces physics. It publishes noisy/delayed
position, orientation, linear velocity, angular velocity, contact, sample
period, sensor latency, actuator activation, energy, power, and thermal
measurements.
Prediction, fusion, attention, interruption, credit, consolidation, and replay
are Rust-executed graph rules.

The implementation is generated by
`scripts/gen_embodied_sensorimotor_core_seed.py` and installed as
`seeds/embodied_sensorimotor_core.json`. The older body-specific seeds depend
on it through `embodied_motor_priors`.

## Biological constraints translated into graph mechanisms

This is a computationally biology-supported design, not an anatomical
simulation.

| Constraint | Graph mechanism |
|---|---|
| Delayed proprioceptive and vestibular feedback cannot be the current body state | `EmbodiedBodyBelief` advances a prior and precision-weights each delayed receipt |
| Motor commands need predicted sensory consequences | Every trial is bridged to the existing efference-copy, sensory-prediction, forward-model, and eligibility-trace machinery before its receipt |
| Multimodal evidence has unequal reliability | Proprioceptive, vestibular, and tactile evidence carry explicit variance and latency; fusion gains follow prior and observation variance |
| Fast correction and slower model revision have different deadlines | Belief fusion, plant estimation, allostatic forecasting, and recovery interruption are hard-real-time; credit, model integration, consolidation, and replay are scoped interruptible work |
| Plasticity must be assigned to the action that caused the result | A normalized receipt is linked to its exact trial as well as its episode and opaque effector model |
| Motor vigor depends on organism state | The local loop combines affective arousal/valence with learned fatigue, thermal load, contact loss, angular instability, and sensory surprise |
| Skill learning continues offline | Reliable controller values consolidate as procedural episodes; default-mode replay can increase the linked forward model's confidence |
| The body and plant are initially unknown | Each opaque effector acquires a receipt-grounded envelope for activation delay, sensorimotor delay, efficiency, elastic recovery, stability authority, fatigue, power, and thermal load |

The predictive-state-estimation constraint follows the established use of
efference copy and delayed sensory feedback in body-state estimation described
by [Miall et al. (2018)](https://pmc.ncbi.nlm.nih.gov/articles/PMC6010151/).
The separation between preparation/prediction and feedback correction is also
consistent with the evidence summarized in
[the motor-cortex research spike](motor_cortex_research_spike.md) and
[the earlier biology-derived upgrade](biological_motor_control_upgrade.md).

## System 1, System 2, and default mode

The local control deadline never waits for unrestricted cognition.

1. A graph-authored motor trial creates its efference copy, forward prediction,
   eligibility trace, and pending receipt records.
2. A physical receipt updates the inferred body state and local recovery
   interrupt on the hard-real-time sheet.
3. The verified receipt authors a `SystemTwoEscalation` scoped only to
   `adaptive_learning` and `embodied_sensorimotor`.
4. The scoped sheet computes signed prediction error, assigns delayed credit,
   publishes the inferred state to the generative world model, and updates
   network-mode evidence.
5. After sufficient verified experience, a reliable controller is stored as a
   procedural `Episode`.
6. When default mode reconstructs that episode, the context authors a second
   scoped request to integrate replay into the linked forward model.

“System Two” here is a scheduling class for interruptible work. Receipt-driven
plasticity is automatic; the graph request is authority to spend compute
outside the hard motor deadline, not a claim that a biological organism
consciously thinks through each weight update.

## No hidden controller

The following remain graph data:

- the current inferred body state and its uncertainty;
- surprise, urgency, vigor, fatigue, and recovery interruption;
- the causal trial-to-receipt identity;
- predicted and observed consequence;
- eligibility and discounted credit;
- controller value and forward-model confidence;
- actuator latency, efficiency, compliance, stability, power, and thermal
  envelope;
- the decision to open soft learning/model work; and
- procedural consolidation and replay.

Python has no action-selection or learning rule. The new
`SensorimotorTransducer` is deliberately mechanical: deterministic seeded
noise, a finite sample-delay queue, and a flat receipt encoding.

## Validation

Focused tests establish that:

- the seed depends on the existing adaptive-control and default-mode cores;
- sensor noise, variance, latency, and repeated-sample identity are explicit
  and deterministic;
- a receipt fuses a body belief and drives existing efference-copy,
  eligibility, signed-error, credit, allostasis, world-model, and
  network-mode paths;
- an outlying noisy observation corrects the prior without replacing it
  wholesale;
- repeated verified outcomes consolidate one reusable procedural episode; and
- an idle/default-mode replay changes the linked forward model.

The existing ground, aerial, and humanoid simulator suites remain the
behavioral regression gates.

## Honest remaining biological gaps

This upgrade supplies a common state-estimation and plasticity spine, but it
does not yet provide:

- learned nonlinear whole-body latent dynamics; the shared belief uses a
  kinematic prior while body-specific graph models carry richer consequences;
- active visual/vestibular co-calibration during locomotion;
- spinal-pattern-generator-like oscillatory primitives that self-organize from
  continuous phase coupling;
- multiple competing forward/inverse models with responsibility weighting;
- synaptic consolidation with interference, sleep-stage structure, and
  selective forgetting;
- explicit pain/nociception and tissue-level injury prediction distinct from
  actuator performance loss;
- hierarchical body-schema remapping after attachment or removal of limbs;
- social imitation and developmental curriculum;
- a hybrid contact/thrust body and canyon task that can falsify transfer from
  terrestrial locomotion to launch, flight, and landing.

The next strongest experiment is not another hand-tuned gait. It is a delayed,
noisy, intermittently dropped sensor protocol across unfamiliar body plans,
with a matched privileged-state control and a mid-episode morphology change.
The graph should retain viability and improve energy-normalized task progress
without receiving body labels or a host policy.
