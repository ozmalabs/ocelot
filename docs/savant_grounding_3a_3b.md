# Savant syndrome grounding — 3a (gifted program) vs 3b (earned understanding)

A research spike (2026-06-27) grounding the creator's insight — "savants have the program GIFTED to them without
understanding" — against the savant-syndrome literature, to sharpen the 3a/3b split and choose the cleanest
machine test of 3b (the understanding a savant lacks). Three clusters; they converge.

## The distinction being grounded
- **3a** = the program operates UNIVERSALLY (law-like generalisation to any instance, NOT a memorised cache). A
  savant HAS this (calendar calc for any date).
- **3b** = the program is UNDERSTOOD: reflectively held, can INTROSPECT it, TEACH it, use it to MODEL ANOTHER
  agent's DIFFERENT program, and EXTEND/transfer it. A savant LACKS this.
- We found empirically (handwriting): within-domain SKILL cannot separate 3a from 3b — both interpolate/perform
  identically. 3b shows only off-performance.

## Cluster 1 — the gift is LATENT/UNMASKED, not earned
- **Acquired & "sudden" savant syndrome** (Treffert 2009, Phil Trans R Soc B; Treffert & Ries 2021, WMJ): savant
  skills surface in neurotypical people after injury/disease (or suddenly, no prior interest) — a fully-formed
  universal program appears with ZERO training time → it cannot have been earned by iteration. Validates
  3a-as-gifted.
- **Mechanism = unmasking, not learning:** paradoxical functional facilitation (Kapur 1996) — release from
  inter-hemispheric inhibition (LATL damage disinhibits the right hemisphere). The program was always present and
  SUPPRESSED; injury removes the inhibitor → "dormant potential in everyone."
- **"Memory without reckoning"** (Treffert): savant memory is procedural/non-declarative/habit-like
  (cortico-striatal), not semantic/declarative (cortico-limbic). "Reckoning" = our 3b. The program runs; the
  reckoning that would let it be inspected/taught/transferred is absent. = 3a-minus-3b, observed in a human.
- CAVEATS: practice is NOT zero — savants rehearse obsessively (Treffert's replication→improvisation→creation),
  so 3a is a gifted KERNEL that practice polishes within-domain (don't model 3a as fully static). And calendar
  calc is law+cache MIXED (rote for past dates, algorithm for future — Cowan & Frith) → claim "law-like coverage
  beyond any plausible cache," not "no cache."

## Cluster 2 — the gift = low-level access WITHOUT conceptual binding; 3b = a declarative SELF-MODEL
- **Snyder (2009, Phil Trans B)** — near-verbatim our thesis: savants have "privileged access to lower level,
  less-processed information, before it is packaged into holistic concepts"; "conceptual networks tend to
  INHIBIT networks concerned with detail." Claims it is latent in all, inducible by LATL inhibition (TMS).
  CAVEAT: the induction evidence is weak/non-uniform (Snyder concedes) — treat "inhibition" as a validated
  FRAMING but a thinly-evidenced intervention.
- **Weak Central Coherence** (Happé & Frith 2006; Happé & Booth 2008): enhanced LOCAL processing, reduced pull
  of the global gestalt — independent convergent evidence that detail and gestalt/meaning are DISSOCIABLE.
- **Calendar calc — the decisive case** (Cowan & Frith 2009, fMRI): savants genuinely CALCULATE (parietal
  arithmetic activation, coverage beyond any lookup = 3a) yet "cannot give an account of how" — systematic
  rule-following WITHOUT conscious/metacognitive access = 3a present, 3b absent.
- **Procedural vs declarative memory** (Squire 2004): non-declarative memory = skills "inaccessible to conscious
  recollection," cannot be verbalised — the architectural home of a program walled off from report.
- **THE MECHANISTIC PAYOFF:** 3b (understanding) is NOT better execution (3a already executes universally) — it
  is a SECOND, DECLARATIVE RE-REPRESENTATION OF THE PROGRAM ITSELF: the system reifying its own running procedure
  into an inspectable, composable, transferable HANDLE (a "concept/label" in Snyder; a declarative entry in
  Squire). Understanding = the program survives EXTRACTION from the substrate that runs it.
- **THE KEY WARNING (Nadia, below): 3a-execution and 3b-self-model are SEPARABLE AND ANTAGONISTIC** — concept
  formation tends to SUPPRESS raw detail access.

## Cluster 3 — which 3b marker is cleanest? TEACH.
- **TEACH/EXPLAIN = the cleanest, best-grounded, machine-testable 3b signature.** Savant-specific (Treffert,
  near-definitional: savants "perform without being able to teach"), mechanistically grounded (implicit/
  automatized acquisition with no explicit representation; Hermelin & O'Connor; Cowan & Frith). The discriminator
  from 3a: emit an EXPLICIT, TRANSFERABLE RULE another agent can EXECUTE — not merely correct or novel outputs.
- **MODEL-OTHERS (ToM)** = the conceptual cousin (teaching IS modelling the learner's program-gap). Historically
  documented (Baron-Cohen mindblindness) BUT confounded: a property of AUTISM not savantism, and its universality
  is contested (Gernsbacher & Yergeau 2019). Noisy machine target.
- **CROSS-DOMAIN TRANSFER / encapsulation** = the structural signature of "gift without integration" (savant
  skills are domain-specific, no robust transfer cases) BUT hard to operationalise ("what counts as a different
  domain?").
- **WARNING — within-domain GENERATIVITY is STILL 3a:** musical savants genuinely IMPROVISE (Sloboda, Hermelin &
  O'Connor 1985) — a rule-based system produces novel valid in-domain outputs without understanding. So a 3b test
  must NOT reward "produce novel valid outputs"; it must demand an EXTRACTABLE, RE-RUNNABLE PROGRAM OBJECT.
- **THE NADIA CAVEAT** (Selfe 1977; Nadia Revisited 2011): as language/concepts developed, the drawing savant
  LOST the gift — 3b SUPPRESSED 3a. Design risk: forcing an explicit/conceptual self-model may DEGRADE raw 3a
  performance. A 3b test must measure understanding WITHOUT assuming it comes free with — or without cost to — the
  gift (consider keeping the raw program and its self-model as SEPARATE channels).

## Convergent conclusion (for the jabberwock's choice)
- **3b is a declarative SELF-MODEL of the program** — reify the running faculty into an inspectable, composable,
  transferable handle. Understanding = the program survives extraction from its substrate.
- **The cleanest test of 3b is TEACH:** the system must emit an explicit, re-runnable program a SECOND agent can
  execute to match its competence — which unifies introspect-your-own-program + model-the-learner's-gap +
  transmit. (Model-others is the cousin; cross-domain transfer the structural correlate.)
- **It must demand an extractable program, NOT novel in-domain outputs** (within-domain generativity is 3a).
- **Guard the Nadia antagonism:** the self-model may compete with the gift — measure 3b without degrading 3a;
  keep channels separate if needed.
- Resonance with the jabberwock's own machinery: it already holds teacher_hook, parent_teacher (ZPD, ostensive
  naming), the universal-ask drive, self_design/reflective_faculty — teaching/self-modelling is native, not foreign.
