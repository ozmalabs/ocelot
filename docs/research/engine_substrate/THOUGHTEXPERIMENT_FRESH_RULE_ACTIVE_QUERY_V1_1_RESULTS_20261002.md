# Thoughtexperiment fresh-rule active query v1.1 — results

**Gate result: pass for fresh-rule structural transfer and isolated query execution across both branch backends.** Four source/native-locked workers independently exposed the new `classify_meter_mode` target and selected `flip_comparison` with the graph Term. Each proposal matched the generic candidate enumerator semantically and preserved the primary target. The active selector chose a one-bit discriminator in all 32 backend/neutral-rate pools; after order freeze and oracle release, only the proposal survived. The proposal passed all four held-outs (positive, negative, neutral, positive), while the fault failed every nonzero held-out. The independent analyzer passes 13/13 checks.

Snapshot-CoW and full-copy branches produced identical candidate predictions, query selections, random-probe predictions, and held-out outputs. Every recorded branch verified its rule receipt and reached a zero-work fixed point. Mean snapshot creation was 21.8 µs per worker. Across neutral rates, average branch creation was 14.0 µs for snapshot CoW and 29.9 µs for full copy (2.13× lower fork time for CoW in this tiny graph). Average candidate-patch time was 192 µs for CoW and 186 µs for full copy; closure was about 11.4 µs in both. End-to-end selector time averaged 64.56 ms versus 65.12 ms, because 200 isolated predictions per pool make branch setup a small share of total work. These four-worker, 100-candidate timings do not establish a general speedup or scaling law.

This is measured structural transfer beyond the existing control-kind and shape targets, using a newly authored symbolic threshold rule and explicit `flip` cue. Python still defines the target, fault, labels, candidate pool, and orchestration; generic materialization applies the edit. It does not establish autonomous diagnosis or open-ended learning. The result validates CoW branch semantics and a local fork-cost advantage while showing little end-to-end gain on this workload. V1's task outcomes remain valid, but its condition timing comparison was confounded by branch reuse; see the [v1 timing amendment](THOUGHTEXPERIMENT_FRESH_RULE_ACTIVE_QUERY_V1_AMENDMENT_20261002.md).
