# Thoughtexperiment event value attribution v1.2 pilot results

## Result

The native v1.2 event journal passes its bounded direct/deferred replay pilot. Three fresh workers passed all independent analyzer checks. Across two authored fixtures, the analyzer independently replays every complete event snapshot in order and obtains exact final node and edge graph parity. It reconstructs and uniquely assigns all eight changed fields; no event snapshots or events were marked truncated or dropped. The direct fixture includes a second no-progress writer event, whose before/after snapshots reproduce the unchanged values. The deferred fixture reaches its preregistered three-step progress budget.

The source lock covers the runner, analyzer, protocol, Rust graph/rewrite/substrate/PyO3 sources, Python wrapper, build manifest and installed native binary. Native build provenance identifies engine `761d4245871a`. Per-worker maximum RSS ranged from 35,212 to 35,604 KiB. Median traced event JSON was 746 bytes for the direct fixture and 2,150 bytes for the deferred fixture. Descriptive median closure CPU times were 0.094 ms traced vs 0.097 ms plain for direct and 0.668 ms traced vs 0.051 ms plain for deferred. These tiny, unpaired fixtures do not support a stable overhead estimate; the deferred difference is consistent with instrumentation doing additional work but must be measured with a larger counterbalanced design.

## Gate status and limits

This is a mechanism pilot, not a pass of the full v1.2 preregistered suite. It covers existing direct and deferred fixtures only. Repeated changes within one field, overlapping writers, restoration to the original value, no-op `SetAttr`, edge deletion/attribute updates under event capture, multi-producer deferred events, deliberate truncation, and oversized values remain unmeasured. The current byte cap estimates retained before-images using Rust `Debug` formatting; the after-image copies are additional and not included in that estimate. The pilot therefore validates event ordering and residual replay for these bounded fixtures, but not budget enforcement, arbitrary mutation-route completeness, causal necessity, diagnosis, proposal utility, natural-task prevalence, or general self-repair.
