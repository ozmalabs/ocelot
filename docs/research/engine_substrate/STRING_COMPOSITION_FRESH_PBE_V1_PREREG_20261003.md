# Fresh string-composition PBE v1 preregistration

Date: 2026-10-03

## Question

How well does the current P4 route apply its supported string operators in compositions not represented as single-operation templates in the prior string PBE fixtures, and what do retrieval and a declared search-budget escalation contribute?

## Frozen suite and arms

Use the 18-task deterministic suite generated by `tests/fixtures/substrate_string_composition_fresh/build_tasks.py`: casefold then substring count; casefold then split; reverse then split; split then concatenate without the separator; reverse then replace; and split then reverse each token. Three parameter variants per family each have four revealed and three disjoint held-out examples. Task inputs and labels are generated before locking. Correctness is exact across every held-out output, including list shape/order and integer counts.

Run four paired arms on a fresh substrate per task: full P4 main; retrieval bypass; retrieval bypass with the existing 500,000-candidate escalation; and independent main replay. Preserve the established route, verifier, and scoring logic. Use balanced arm order. The escalation applies only to its named arm. Do not tune the fixture or policies after capture.

## Measurements and gates

Lock protocol, generator, generated fixture, benchmark wrapper and benchmark implementation, analyzer, P4 adapters/seeds, native synthesizer/extension/build manifest, and Cargo lock before running. Require fresh native build and stable hashes. Independently recompute all 126 fixture outputs and replay main outcomes. Report per-task/family exact passes, accepted false programs, gaps, route/rung, candidate counts/budgets, wall/CPU time and peak RSS. Retain every false accept and timeout.

## Claim boundary

This is a seeded authored suite of supported DSL compositions, not natural-string task prevalence, open-ended operator invention, or a population estimate. Its tasks are new relative to the prior fixtures, but their operators and compositions are human specified. Do not interpret a null main/retrieval difference as equivalence.
