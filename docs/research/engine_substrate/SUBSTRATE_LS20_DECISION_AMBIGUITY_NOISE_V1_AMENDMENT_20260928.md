# LS20 decision ambiguity/noise v1 execution amendment

The first locked preflight stopped on its first attempted noisy arm before any task result row was written. The wrapper had temporarily replaced the production recognition function and then called through that replaced function while passing `_see`; this raised a `TypeError`. No outcome was observed or used to change the design. The corrected runner now retains the original recognizer and injects the noisy observer through its supported `_see` argument. The failed preflight lock is retained as `ls20_decision_ambiguity_noise_v1_preflight_lock_20260928.json`; it is not the execution lock. The amended runner, this amendment, and the independent analyzer are source-locked before collection. All preregistered task cells, seeds, noise levels, scoring, and gates are unchanged.
