# Thoughtexperiment isolated observer memory v1.2.12 amendment

The v1.2.11 functional and checkpoint checks pass, but its isolated-arm `ru_maxrss` is identically 751,016 KiB because those children start after the coordinator has retained large capture data. Treat the v1.2.11 high-water values as contaminated and superseded for arm memory comparison. These deltas still include retained Python/native report objects at return and do not measure transient per-allocation peaks.
