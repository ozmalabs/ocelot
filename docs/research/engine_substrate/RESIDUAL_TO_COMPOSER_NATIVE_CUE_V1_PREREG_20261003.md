# Native residual-to-composer cue derivation v1 protocol (2026-10-03)

## Question

Can a native graph rule turn raw actual/expected action outcomes plus held action-relation facts into a composer cue, allowing the existing graph composer to propose a repair inside an isolated CoW branch?

## Design

Use the 13-case residual panel from the earlier Python cue-derivation study: four opposite cardinal actions, four orthogonal or same-direction controls, two unknown-action controls, one missing-expected control, one zero-displacement control, and one absent-target control. Positive action outcomes are generated by the faulted navigation fixture; controls carry the stated synthetic residuals. Every branch inherits the same four directed `OppositeActionPair` facts (the two inverse cardinal pairs in both directions). These are declared task ontology inputs, not inferred labels.

The baseline and candidate branches fork the same primary snapshot. Both pass only `actual` and `expected` to `induce_concern`. The candidate branch additionally installs one generic native rule: when an `OutcomeResidual` matches an `OppositeActionPair`, mint a `CapabilityAxis` with the existing `flip_comparison` cue. It must not inspect task case IDs, target rule names, or the expected edit label. The ordinary graph composer consumes that axis and proposes a structural variant. The baseline receives no cue rule. Held-out outcomes are evaluated through the existing isolated candidate scorer.

## Gates

- All four opposite-action cases derive a cue, propose `flip_comparison` for `hop_descend_gradient`, and pass both held-out directions.
- Orthogonal, same-direction, unknown, missing, and zero-displacement controls derive no cue and emit no proposal.
- The absent-target control may derive the cue but must not emit a proposal.
- Baseline branches do not derive a cue or emit a proposal.
- Both branch graph/rule mutations remain isolated from primary until a single `ExperimentResidual` is explicitly returned. The returned primary contains the result and candidate data, with no exploratory rule additions or branch graph changes.
- Source, native binary, and input hashes remain stable; the engine is not stale.

## Limits

The native rule is authored for this experiment, and the action-pair facts are supplied from the task ontology. This measures moving a bounded mapping from Python into native graph execution; it does not show the substrate inventing the mapping, learning action geometry, or discovering a new operator. The fixed panel is not a natural task sample or a general self-improvement result.
