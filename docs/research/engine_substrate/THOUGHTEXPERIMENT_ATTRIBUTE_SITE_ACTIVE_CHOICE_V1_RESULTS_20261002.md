# Thoughtexperiment attribute-site active choice v1 — results

**Corrected analysis: bounded candidate-selection gate passes.** In four workers, the direction-omitted ordinary composer abstained and the generic host enumerator supplied both ordered swaps. The harness compared the unchanged fault and both edits in fresh isolated branches over 32 backend/alias conditions. Before oracle release, the native-Term selector chose the same maximum-disagreement probe: the forward edit predicts separately while fault and reverse agree. After oracle release, the forward candidate was the sole survivor in 32/32 conditions. It passed all five held-outs per worker; fault and reverse each failed at least one nonzero case per worker. All recorded branch receipts and fixed points passed, and primary state was preserved. The corrected independent review passes 14/14 checks.

For three binary-output hypotheses, 1.0 bit is unattainable: the maximum is 0.9183 bits for a 1-vs-2 partition. Every chosen probe reached that maximum. The random one-shot baseline distinguished fault from forward in 6/16 conditions per backend, while active selection distinguished the full candidate set in 16/16 per backend. The literal one-bit preregistered threshold is therefore invalid and not met; the corrected, mathematically attainable maximum-entropy analysis is disclosed in the [amendment](THOUGHTEXPERIMENT_ATTRIBUTE_SITE_ACTIVE_CHOICE_V1_AMENDMENT_20261002.md).

Costs expose the current architecture boundary. Candidate creation remains host-side: the ordinary composer attempt averaged 24.15 ms and generic candidate enumeration 0.413 ms per worker. Active selection averaged 107.1 ms per pool with CoW branches and 189.0 ms with full-copy branches; these include predictions across 100 candidates and three hypotheses. Mean individual fork, patch, and closure costs were 0.140, 0.207, and 0.0124 ms. The test shows useful substrate-controlled evidence selection among a supplied finite set, not autonomous structural invention, task generation, domain completeness, or oracle trust.
