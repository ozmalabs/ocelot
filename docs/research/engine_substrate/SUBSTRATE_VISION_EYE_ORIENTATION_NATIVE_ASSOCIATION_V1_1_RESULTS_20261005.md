# Native orientation association v1.1 results

The amended source-locked capture and independent analyzer passed all integrity gates across six paired seeds. Each run used the exact position-held-out v1 schedule and 9,600 labeled training presentations; all 32 probes used the same masks, positions, and learned visual weights as the paired unsupervised panel. The first v1 attempt is preserved as a failed admission run: it stopped before training when the grammar rejected an undeclared Type-2 edge. V1.1 added explicit typed grammar productions for the evaluation relations before adding graph facts.

During training, native graph rules accumulated WUnit activation by teacher-supplied orientation class. Independent reconstruction from all step-level native activations matches every stored association count within the preregistered floating-point tolerance. At evaluation, a second graph rule selected one class per probe from the learned association scores; all 192 worker queries produced exactly one graph prediction. Association values and visual weights remained unchanged during the frozen probes.

Native graph prediction scores **30/48** on the eight held-out probes per seed. It ties or exceeds the external nearest-class-mean readout in four seeds, falls one probe below it in two, and totals 30/48 versus 31/48. It scores 29/48 under the paired initial random projection, 24/48 for centroid/count controls, and 48/48 for the translation-aware pixel template. Native class counts are 20/24 horizontal and 10/24 vertical, showing a prediction bias. This run demonstrates a graph-resident supervised association and readout under externally supplied labels and rules; it does not show a transfer-accuracy gain, independent rule construction, or self-improvement.
