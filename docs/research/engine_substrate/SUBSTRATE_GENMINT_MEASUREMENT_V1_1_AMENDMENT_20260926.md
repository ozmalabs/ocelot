# GenMint measurement v1.1 provenance amendment

This amendment preserves the v1 learning conditions and six semantic gates. It changes only run capture and provenance: the v1.1 runner requires a pre-run lock over the protocol, runner, learning seed, rule/host sources, analyzer, and loaded native binary; it records the shared `substrate-run-manifest-v1`, a parent stdout/stderr log, and the complete Python argv/environment. The report is written to a new path and does not overwrite v1.

The fixed 400-coloring control remains a finite authored null family, the declared MDL token model remains unchanged, and the 2-D integer-linear boundary remains the claim boundary. This is not a general learning or tractability estimate.
