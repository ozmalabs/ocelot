# Vision substrate multi-seed response replication v2.1 preregistration

## Question
Across independently adapted checkpoints, do the v1.9 orientation/phase response and exact closure termination patterns replicate?

## Design
For each valid v2.0 checkpoint (seeds 20260935, 20260936, 20260937), restore the exact graph and run the v1.9 response-phase contract under root-scoped rules. Run 25 conditions per seed: both blank, plus four orientations (0°, 45°, 90°, 135°) by two phases (0, π/2), with B-only, A-only, and both-sheet presentations. Use the original v1.9 binary grating construction, rate-write snapshot, graph digest, exact repeated-graph detection, and 512-pass trace cap. Record each pass and resume checkpoints after every condition. This is 75 response trials total.

## Integrity and analysis
Require exact source-lock match, exact restored checkpoint digest, source stability, and all v1.9 analyzer-equivalent response equations/closure classifications. A trace-cap result is unresolved in this study and will be followed by native full-closure replay under an explicit amendment, as in v1.9.1. Compare rate-write activation, terminal/cycle-orbit response, termination class, and closure work across seeds. Report missing or failed seed/condition records; do not replace them.

## Claim boundary
This measures seed sensitivity on one small, synthetic, fixed-frame vision task family under root-scoped rules. It does not validate natural-task locality or large-scale commodity-CPU performance.
