# Thoughtexperiment active probe selection v1 — results

**Gate result: pass for finite active selection between supplied alternatives.** Four source/native-locked workers each ran alias pools at 0%, 50%, 90%, and 99% over 100 candidate observations. Across all 16 captures, the native-Term selector returned a valid maximum-entropy discriminating probe (1 bit); after the query was frozen, the task oracle left only the `key` hypothesis, which matched all 20 separate held-out discriminators. All source hashes remained stable.

The random one-probe baseline discriminated in 4/4 trials at 0% alias, 2/4 at 50%, and 0/4 at 90% and 99%; the actual pool discriminator proportions were respectively 100%, 50%, 10%, and 1%. Mean selector time was 1.32–1.55 ms on this host. These are small synthetic results with four workers per condition; they are not estimates of broad task performance or a hardware speed claim.

The measured ability is useful for the thoughtexperiment loop: given two explicit candidate rules and a finite pool, the substrate can choose an input that makes them disagree, and an external outcome can resolve the supplied alternatives. The hypothesis Terms, candidate generation, task semantics, oracle function, and evaluation remain Python-owned; this does not establish hypothesis discovery, structural proposal generation, dimension induction, new-primitive invention, or self-improvement. The next gate is to connect this query to competing substrate-composed structural proposals on a fresh target rule, then score those proposals on sealed held-out tasks while accounting for host work.
