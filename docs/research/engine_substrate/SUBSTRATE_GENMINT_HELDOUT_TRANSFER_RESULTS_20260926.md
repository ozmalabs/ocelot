# Full-seed GenMint held-out transfer results

The captured 180 full-seed sequences passed the amended integrity checks and all three clean-training/clean-held-out positive cells. In each positive geometry, GenInfer mints `[1,1,0,2]`, the production loop re-decodes the training observation as `recognized_transformed` with zero CapabilityAxis quanta, then selects that newly minted linear generator for the staged held-out base and predicts both held-out relations exactly in all 15/15 sequences.

On uniform +1 p0 training perturbations, all 15 enabled sequences acquire the same linear matrix and use it to predict clean held-out relations exactly. This differs from direct residual extrapolation: the generator node stores the matrix, while the held-out base is a distinct shape, so its residual is recomputed there. Inconsistent +1/+2 training perturbations acquire the generator in only one of the three layouts (10/30 enabled sequences after the held-out-condition cross); the other 20/30 mint a quantum instead. The acquired-generator subset predicts clean heldouts exactly.

Route attribution changes the interpretation of apparent held-out success. Every held-out observation reaches `recognized_transformed`, including all 90 induction-disabled controls, because the two-row held-out patterns can also be explained by a pre-existing `scale2` generator. For each training condition, all 15 enabled sequences whose held-out target itself carries the p0 +1 shift select `scale2`, not the newly minted linear map. Those cases therefore provide no evidence of GenInfer-generator transfer. Likewise, in the inconsistent condition, ten of fifteen clean-heldout cases select `scale2`; five select the learned linear generator and predict exactly. Status alone is not a transfer metric.

The v1 runner took 12.87 s for 180 sequences. Median native closure time on clean training observations was 32.79 ms with GenInfer enabled versus 1.21 ms disabled; uniform-shift medians were 34.22 versus 1.00 ms. These descriptive single-run timings expose an acquisition-cost premium for this evaluator search; boot and total task cost are not separated, and no memory profile was recorded. The GenInfer arm replaces one quantum per training observation on these clean and uniform-shift fixtures with one generator mint and zero quanta, but this is not yet an amortization result.

This is a controlled 2-D authored family. It demonstrates generator acquisition and transfer for clean held-outs inside this fixture; it does not show general capability gain over the frozen seed, because the baseline can use `scale2` on the two-row pattern. Next increase the held-out pattern size and discriminability, use multiple independent generator families, and run a paired amortization curve across repeated reuse counts with route-specific held-out accuracy and resource costs.
