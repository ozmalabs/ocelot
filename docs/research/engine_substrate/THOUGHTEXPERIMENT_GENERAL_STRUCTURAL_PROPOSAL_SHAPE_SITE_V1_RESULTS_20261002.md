# General structural proposal shape-site direction v1 — diagnostic result

**Gate result: pass for cue-conditioned site selection; diagnostic only.** Four workers captured proposals before any held-out outcomes. The exact `key to signature` cue selected `sd_mint_quantum`, `swap_term_leaf`, and the ordered site `key -> signature` in all workers. The reversed cue selected `signature -> key` in all workers. Both variants matched their corresponding host reference candidates by semantic digest. With separate `key` and `signature` terms but no directional phrase, the graph Term found tied site scores and abstained in all workers.

Held-out scoring passes the cue-matched proposal in 4/4 workers, with all three generated-axis cases and the fixed-point case correct, valid receipts, and primary preservation. The reversed proposal fails the three generated-axis cases in 4/4 while preserving receipts and primary state. The full 24 host candidate outcomes also pass their receipt/isolation checks; each worker has both passing and failing candidates. The analyzer passes all twelve checks.

This resolves the earlier shape smoke's wrong-direction choice by making both directions explicit `EditSite` graph nodes and selecting a unique site with a native Term. Python still extracts attribute-key pairs and applies the selected rewrite. The exact cue names the desired direction, and prior exploratory outcomes were already visible, so this is not direction discovery or first-look generalization. It measures that the graph selector can follow a directional cue and abstain on ambiguity in one authored shape-axis family. Median composer time is 255.77 ms for the key-to-signature phrase and 38.96 ms for the reverse phrase; four repetitions show a large and unexplained timing asymmetry, so these timings are diagnostic only and no performance conclusion is drawn.

Next, vary the cue surface without naming the target edit directly, add independently authored shape-rule families, and measure how a substrate-generated probe or held-out residual selects orientation. Then evaluate recurrence, whose useful domain-specific repair may require an operator beyond these four generic EditOps.
