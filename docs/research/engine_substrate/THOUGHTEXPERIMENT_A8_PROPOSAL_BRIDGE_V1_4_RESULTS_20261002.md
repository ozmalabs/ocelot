# Thoughtexperiment A8 proposal bridge v1.4 — cardinal displacement generalization

**Date:** 2026-10-02  
**Status:** All eight preregistered analyzer gates passed.

## Protocol integrity and source attribution

The 38-entry lock includes the loaded native binary, both runner/analyzer and adapter sources, the v1.4 amendment, and prior evidence. Canonical rule-clause parity matched all three active graph composer rules after firing. Four parity mutations (operator, guard literal, effect literal, effect order) were rejected. Seven semantic-digest controls passed: engine-generated metadata is ignored, while target keys, match ordering, guards, effect operators, literals, and effect ordering affect identity. Four source-stable order workers passed the prompted graph-attribution and target-preservation gates; all no-cue calls were graph-served and abstained. Orders contained no held-out outcome fields.

## Held-out generalization

The held-out set contains eight previously unscored cardinal target positions: offsets of 2 and 4 from avatar coordinate `(5,5)` in each direction. Across four isolated worker captures, the graph-authored `flip_comparison` candidate passed all 32 worker/state outcomes, matched the host `flip_comparison` candidate under the preregistered semantic digest, produced valid receipts, and preserved each primary graph. All six host candidates were scored in each worker; exactly `flip_comparison` passed in each, while the five alternatives failed. The source-rule control passed and the fault-rule control failed for every worker.

Median prompted-selection cost was 140.3 ms; host default-prefix cost was 79.1 ms; exhaustive host audit cost was 133.0 ms. Thus the graph proposal generalizes across the tested cardinal displacements but does not improve measured selection cost. The four workers use the same authored rule and coordinate fixture, so they are isolated repetitions rather than independent task families or natural-task samples.

## Interpretation and artifacts

This extends the A8 evidence from two adjacent held-out directions to eight held-out cardinal positions at two distances. It demonstrates cue-conditioned graph authorship, graph-path abstention without the cue, and proposal utility on one chosen-action navigation rule. It does not test obstacles, novel targets or task families, autonomous diagnosis, open-ended candidate generation, adaptation after deployment, or self-improvement.
