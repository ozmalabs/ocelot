## Question and arms

Does two-event compatible source experience improve normalized target learning-curve AUC in one common ordinary native learner, compared with the stronger of fresh learning and equal-work same-target map construction? Every arm receives the same ordered pair of target receipts and is scored at target interactions 0, 1, and 2. The directions are `heat_to_thermal` and `lever_to_latch`; target context epochs are 5 and 6, fixed by allocation seed parity.

- `fresh`: no external source and no optional map work.
- `compatible_source`: two compatible source actions, two native map-pair views, five verification queries, and a source prior only after verified map and target-effect evidence.
- `wrong_source`: two inconsistent source actions and equal map/verification allowance; rejected maps remain recorded while ordinary target learning continues.
- `same_target_map_work`: no external source; two reciprocal map views use the same target receipts and import no source prior.

All target receipts are assimilated by the same ordinary learner path. All outcomes are scored against an independently executed simulator action on an unseen object at checkpoints 0/1/2.
