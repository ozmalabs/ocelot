# Vision-eye live corruption replay v1 results

The source-locked capture completed successfully across 12 workers (six seeds paired across square and cross maps). Every worker passed the 36,000-step training schedule, 75 clean probes, 240 corrupted held-out probes, source-stability check, and frozen-weight check. Learned weights match the earlier v2.1 capture exactly; clean live activations and winners match the v2.1 record; corruption masks match the deterministic post-hoc masks; and live activations reconstruct from captured weights with maximum absolute error `1.11e-16`.

The original analyzer's exact-max gate failed on seven of 2,880 corrupted probes: in each case the native winner's reconstructed score is one ULP below the maximum under a different summation order. The amended analysis retains this failed preregistered gate rather than applying an unregistered tolerance. Live winner region accuracy is: square 272/288, 233/288, 183/288 at 25%, 50%, 75% dropout and 285/288, 272/288 at 25%, 50% added background; cross 205/288, 176/288, 108/288 at those dropout levels and 192/288, 197/288 under added background. The offline set-valued tie scorer differs from the native single-winner outcomes in 32 probes. These scores are on synthetic position-coded masks; they do not establish natural-image robustness, online adaptation, or semantic vision.

The original capture and lock are valid and preserved. The analyzer was revised after capture to report floating-point and tie semantics accurately; its current hash differs from the analyzer hash locked for the run. The revised report is therefore exploratory rather than an independent preregistered pass. See [protocol](SUBSTRATE_VISION_EYE_CORRUPTION_LIVE_REPLAY_V1_PREREG_20261005.md), [amendment](SUBSTRATE_VISION_EYE_CORRUPTION_LIVE_REPLAY_V1_AMENDMENT_20261005.md), [runner](../../../evaluation/substrate_capability/vision_eye_corruption_live_replay_v1.py), [capture](../../../evaluation/reports/vision_eye_corruption_live_replay_v1_20261005.json), and [amended analysis](../../../evaluation/reports/vision_eye_corruption_live_replay_v1_analysis_20261005.json).

The final source-locked post-hoc v1.4 analysis reproduces the deterministic corruption set construction before summing, preserving the offline scorer's set iteration order. It reconciles all 2,880 corruption probes, confirms exact-max membership for 2,873/2,880, and finds all seven remaining native winners within one ULP; maximum activation absolute and relative errors are `1.11e-16` and `6.99e-16`. The strict preregistered gate remains failed. The native single-winner and offline set-valued region scores differ on 32 probes. The v1.1–v1.3 attempts are preserved with amendments documenting their respective analysis defects. See [v1.4 protocol](SUBSTRATE_VISION_EYE_CORRUPTION_LIVE_REPLAY_V1_4_POSTHOC_ANALYSIS_PROTOCOL_20261005.md), [v1.4 analyzer](../../../evaluation/substrate_capability/analyze_vision_eye_corruption_live_replay_v1_4.py), [v1.4 analysis lock](../../../evaluation/substrate_capability/vision_eye_corruption_live_replay_v1_4_analysis_lock_20261005.json), and [v1.4 analysis report](../../../evaluation/reports/vision_eye_corruption_live_replay_v1_4_analysis_20261005.json).

The v1.5 source-locked rule-oracle analysis resolves the interpretation: every one of the 2,880 native winners is an exact maximum of the activation values captured from the live graph. There are 115 probes with multiple exact native activation maxima; in all 115, the graph chooses the first maximum in WUnit order, matching the `Argmax` evaluator's first-encountered tie rule. This shows the seven ULP differences are between native act values and offline weight-sum reconstruction, not a live selector inconsistency. The 32 region-score differences remain because native scoring emits one tie-broken winner while the offline metric scores the tied maximum set. The analysis is still post-hoc and specific to this task.
