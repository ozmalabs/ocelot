# Cognition manifold integration contract v1

The native `future_manifold` projector remains the sole implementation of retained, lost and escape residuals. GWM may supply candidate transitions and uncertainty; it cannot certify feasibility. Every candidate records its source model, model epoch, owner, frame, horizon, transition list and uncertainty envelope. A missing transition or missing model yields an unresolved candidate set, never an invented wait/action path.

Projection preserves each time-indexed cell and topology link and returns full residual shapes. A funded refinement creates a new projection version with a request key tied to the candidate/model/manifold epochs. Approval debits once; denial, exhaustion, model change or manifold invalidation terminates the request and restores temporary state. A stale refinement cannot be reused. `wait`, `refine` and `commit` are compared against the same target manifold, and goals only break equal-intervention ties. An incomplete horizon or exhausted budget cannot certify retention.

ThoughtManifold uses the same projection and residual contract. Detached imagery is bounded and source-attributed; it may create a candidate but cannot ground an observed/verified fact. Grounding requires an external observation or an exact verifier receipt. Supplied-path behavior is the parity reference; candidate production from GWM is an additional path with independent mechanism and held-out evaluation.

## E2.1 implementation inventory and parity boundary

The current Python decision owners are:

| Entry point | Decisions it currently owns | E2 destination |
|---|---|---|
| `domains/regulated_train_of_thought.py::run_regulated_train_of_thought` | Initial topic and measured signature projection remain adapter inputs; concept/aperture deviation, width steering, frontier choice and termination move to `ThoughtManifold` rules | Python ingests topic/signature evidence and candidate segments, then reads graph state |
| `domains/minting_train_of_thought.py` regulated trajectory loop | Topic/signature selection, frontier and continuation around `train_of_thought.run_inner_conversation` | Shared graph trajectory/controller; preserve mint-specific outputs as separate readout effects |
| `domains/global_workspace.py` curiosity valuation helper | Calls `_trajectory_deviation` for a topic-level value | Read the graph's deviation signal after E2, without recomputing it in Python |
| `domains/train_of_thought.py::run_inner_conversation` | Generates concept trajectories using attention-width traversal | Remains the legacy parity producer until a graph-native candidate producer is available; do not delete before parity is demonstrated |

Only `regulated_train_of_thought` is the public E2 migration target in this phase. The minting path and low-level trajectory generator are callers/dependencies to preserve; they are not silently rewritten by removing a helper. The two tube modes (concept ancestry and aperture-projected signature) are distinct parity fixtures. Returned topic strings and widths are candidate imagery and have no grounding authority. Exact transition evidence or external observation is required before any grounded reading can be emitted.

The current E2.2 graph seed selects an initial topic from caller-supplied `candidate_topics` and `tube_region`, then accounts for each ingested `ThoughtSegmentInput`, computes concept-region deviation, steers discrete width, tracks visited topics and selects the next fresh frontier topic. Its frontier includes unseen members of the supplied concept region, preserving the legacy continuation behavior. It records reached concepts as candidate imagery and cannot create grounded readings.

Both concept-region and aperture-grain routes use the shared graph-owned ThoughtManifold lifecycle. The concept route can have its region assembled from graph ancestry. The aperture route supplies static signature coordinates plus raw codebook field values and global quantum/half-width metadata as `ThoughtRawSignatureCoordinate` nodes. ThoughtManifold rules apply the Observer's per-dimension `resolves` gate and `grain`, clamp the rounded quanta, mark hidden/zero coordinates dark, assemble the set-point signature and derive coordinate keys. Rules own aperture deviation, width, next topic and stop state; the adapter does not call `_admitted_signature` on this route. The adapter still obtains the static lexical/relation coordinate portion with the shared `concept_signature` extractor and mechanically reads the codebook fields. Before each segment, the graph opens one `ThinkingBudgetRequest`; the adapter invokes the producer only after a same-epoch debit. Disabled or exhausted budgets terminate without generation, and an epoch change prevents the segment from becoming an accounted ThoughtManifold step. The public result retains `segments`, `width_trace`, `deviation_trace`, `recovered_total`, `stop_reason` and `tube_region`. The adapter enables the opt-in policy only for the explicit call and restores its prior value on all exits, including a candidate-producer exception. The graph keeps a bounded detached imagery buffer while retaining provenance-linked segment traces. Numeric signature coordinate extraction parity beyond the current codebook field and static-coordinate path remains to be evaluated.
