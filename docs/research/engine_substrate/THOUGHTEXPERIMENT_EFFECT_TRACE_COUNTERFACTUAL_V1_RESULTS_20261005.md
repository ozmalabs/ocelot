# Thoughtexperiment effect trace versus rematch counterfactual v1 results

The three-worker source-locked capture passes corrected analysis over all 80 generated cases. Each compares the endpoint-only observer plus (a) effect candidates tested in ascending order, (b) a complete graph/rule rematch followed by one candidate test, and (c) effect-level tracing followed by one candidate test. All three policies identify the actual effect and the omission branch removes the queried violation. Full rematching and tracing each need one counterfactual branch; endpoint-only candidate search averages 7.775 branches. All 80 primary graph and graph/rule revision receipts remain unchanged across branch work.

On the complete 80-case panel, median end-to-end diagnosis time is 1.512 ms for endpoint-only candidate search, 0.526 ms for graph/rule rematching, and 0.567 ms for effect tracing. Median CPU time is 1.543, 0.534, and 0.575 ms respectively. Thus the trace does not beat the full-rematch baseline here; rematching is about 7% faster at the pooled median. At 32 effects the rematch median is 0.772 ms versus 0.919 ms for tracing. The 16-effect stratum slightly favors tracing, so no universal ordering is inferred from 20 cases per size. Observer timing includes branch fork and closure; rematching also includes graph export plus conjunction join; branch timing includes shared-page fork, branch-local rule replacement, one-firing closure, and outcome check. Common case/snapshot creation is excluded.

Counterfactuals use the native `shared_graph_pages` snapshot backend. The cases are authored conjunctions of 4–32 slot edges with one `SetAttr` per binding and a supplied failing node; all rule effects are easy to rematch from the graph. This is stronger evidence than the earlier event-report-only selector but does not test difficult joins, deferred effects, dynamic term values, realistic task routes, or whether the firing's matcher binding can be retained more cheaply than either strategy. The current trace's stress-case memory cost remains material, so this result does not justify routine effect tracing.
