# Omniglot contrastive-verdict historical reanalysis v1

**Type:** retrospective, read-only reanalysis of a completed 2026-07-05 result; not a preregistered new run.  
**Question:** Do the archived paired episode records reproduce the documented accuracy and harm statistics for the run-37A top-two contrastive verdict?

## Inputs

- `results/run37a_checkpoints/eval_run37a.json`: 400 paired global/contrastive predictions, expected complete at 20 blocks.
- `results/run37a_checkpoints/report.json`: run summary generated by the historical runner.
- `results/run26_checkpoints/eval_baseline.json`: baseline global predictions and episode keys.
- `results/omniglot_gate_run37a.log`: historical execution and reporting log.
- `results/run37a_checkpoints/guard.json`: historical block-0 global-prediction and staging guard.
- `docs/research/vision/OMNIGLOT_ARC.md`: historical arc record and source-commit attribution.

## Reanalysis, fixed in advance of this script's execution

Verify completeness, key uniqueness, and exact paired episode identity; independently reproduce the baseline global arm; calculate accuracy, Wilson 95% intervals, fixed/broken discordances, exact two-sided binomial McNemar p-value, per-alphabet counts, true-rank ceiling, and contrastive decision counts. Compare reproduced values to both the archived JSON summary and the historical log. Do not rerun inference or edit source/data/checkpoints.

## Evidence boundary

This validates the archived output and its reported arithmetic. The historical document attributes the run to commit `cca938fd`, but this checkout's Git history is an imported snapshot and does not provide that historical commit object. The archived raw capture does not include a complete source/input hash lock. Therefore this analysis is historical artifact verification, not a current-source reproduction or end-to-end source-provenance proof. The task is 20-way Omniglot one-shot recognition with character IDs as labels; it does not measure natural language, general perception, or the generated experiment-judge rule.
