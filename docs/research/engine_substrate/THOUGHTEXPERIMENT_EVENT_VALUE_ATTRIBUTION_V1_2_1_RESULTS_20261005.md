## Result

Replaying the events matches the exact final graph. Target-only matching marks the final changed field ambiguous between two writers, while the ordered value sequence identifies `writer_two` as the last writer. Across all fixtures, replay checks validate every complete before-state against the preceding state and reproduce the final nodes and edges exactly; no events or snapshots were dropped or truncated.

The source lock covers the runner, analyzer, protocol, Rust graph/rewrite/substrate/PyO3 sources, wrapper, build manifest, and native binary. This supports event ordering for one repeated target written by two distinct direct rules in a bounded settlement. It does not test multiple writes inside one event, long repeated-write closure, deferred/direct conflict on the same field, edge deletion/attribute overlap, deliberate truncation, or byte-budget correctness. The budget remains a `Debug`-based estimate over retained before-images; after-image copies are additional. Timing is descriptive only for these tiny authored fixtures.
