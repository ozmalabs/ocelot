# Thoughtexperiment event value attribution v1.2.2 results

## Result

The current-source v1.2.2 pilot passes all independent checks across three fresh worker processes and five authored fixtures. Complete event replays for direct writes, deferred writes, and two overlapping writers reproduce all event before-values and the exact final graph. The overlap transitions remain `writer_one: 0→1`, then `writer_two: 1→2`; target-only matching is ambiguous, while the ordered event sequence identifies the last writer.

The oversized-value control exceeds the per-event estimated byte cap, emits no partial node pair, and marks its event/report truncated. The 520-node control reaches the 512-object per-event cap, retains 512 complete node pairs, and visibly marks the event truncated. Across the measured traced fixtures, retained representation estimates stay under the configured 4 MiB/report and 16,384-object/report limits. Maximum worker RSS is 46,740–47,184 KiB. The two deliberate truncation fixtures are excluded from complete event replay; their plain, traced, and exact graph statuses and final states still agree.

The source lock covers the preregistration, runner, analyzer, Rust mutation/journal and binding sources, Python wrapper, build manifest, and native binary. Independent analysis confirms three distinct worker PIDs, stable source hashes, exact ordinary/traced/exact closure parity, and expected truncation receipts. ## Limits

The byte measure is a `Debug` representation-size estimate of both before and after values, not exact heap usage, encoded JSON bytes, or a hard RSS cap. Computing the estimate itself formats values and can allocate temporary memory. The fixtures exercise per-event byte and object caps but do not saturate the per-report byte/object caps. The report currently exposes report-level configured budgets and consumed estimates; the next instrumentation revision should add per-event consumed estimates and exact encoded-byte counts or use a bounded serializer. Long repeated-write closure, same-field direct/deferred conflicts, multiple mutations within one invocation, deletion/retraction overlap, natural-task prevalence, target-blind diagnosis, and repair utility remain open.
