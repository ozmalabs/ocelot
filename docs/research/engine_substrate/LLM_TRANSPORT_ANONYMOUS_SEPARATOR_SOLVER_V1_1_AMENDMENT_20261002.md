# LLM transport anonymous-separator solver v1.1 amendment

Date: 2026-10-02

The v1 end-to-end capture passed exactness, sign, and source gates but showed that the generic conditioning implementation rescanned factor lists inside every separator assignment; its two-candidate solve was slower than monolithic JT. V1.1 hoists component unary/internal/boundary factor incidence and component state configurations out of that loop. The data, random anonymization, proposal search, candidate set, and timing scope remain unchanged. V1.1 stores each candidate state and anonymous factors so the independent analyzer can directly rescore every candidate, not just the selected one. V1 remains a diagnostic baseline; only v1.1 is the amended result.
