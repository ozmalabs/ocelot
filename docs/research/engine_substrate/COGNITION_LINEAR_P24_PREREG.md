## Question and arms

Does two-event compatible source experience improve normalized target learning-curve AUC in one common ordinary native learner, compared with the stronger of fresh learning and equal-work same-target map construction? Every arm receives the same ordered pair of target receipts and is scored at target interactions 0, 1, and 2. The two independent finite-world directions are `heat_to_thermal` and `lever_to_latch`; context epochs 5 and 6 are assigned by the fixed seed parity in the allocation.

- `fresh`: no external source and no optional map work.
- `compatible_source`: two independently receipted compatible source actions, two native map-pair views, five recorded map verification queries, and a source prior only after verified map and target-effect evidence.
- `wrong_source`: two independently receipted inconsistent source actions, the same map-pair and verification allowance, with rejected mappings retained and ordinary target learning continuing.
- `same_target_map_work`: no external source; two reciprocal map views spend the same optional map-work allowance using the shared target receipts and import no source prior.

No arm-specific answer, target outcome, prediction, or task is selected by host logic. All scores are from a separate simulator action on the unseen object after each checkpoint. The outcome and target receipts enter the same ordinary native learner in every arm. Source acquisition, map effort, verification, shared-budget debits, native work, graph footprint, and elapsed stream runtime remain separately recorded.

## Frozen limits and scoring

Every target arm receives exactly two target actions; compatible and wrong-source arms receive exactly two source actions; all arms use zero external model queries. Each target/source learner is bounded by 80,000 native rule steps and 100,000 canonical graph bytes. The standalone native budget is created with requested amount 100, native capacity 16 and capacity ceiling 64; approved debits are exactly 2 for fresh and 4 for each map-work arm. Any ceiling violation, missing arm, receipt mismatch, double credit, incomplete control, provenance mismatch or missing row invalidates the structural panel; no row is dropped.

The primary is family-specific compatible-source AUC minus `max(mean fresh AUC, mean same_target_map_work AUC)`, with a required gain of at least 0.10. The stronger source-free arm is selected from family means and recomputed in every paired-stream bootstrap resample. Use 10,000 paired stream-cluster resamples, a 99% percentile interval, null-centered one-sided bootstrap tail, fixed family seeds, and Holm adjustment at α=.01 across the two family primaries. Report final accuracy by arm and a paired 99% interval; compatible-source final accuracy may not be more than 0.02 lower than the stronger source-free mean. All-success, all-failure, flat and incomplete outcomes are retained; flat AUC gains are exactly zero. Report wrong-source minus fresh, same-target-map-work minus fresh, and compatible-source minus fresh as secondary contrasts.
