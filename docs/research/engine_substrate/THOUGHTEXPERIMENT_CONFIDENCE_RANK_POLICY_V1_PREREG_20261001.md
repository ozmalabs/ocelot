# Thoughtexperiment confidence ranking policy v1 — preregistration

**Question:** After an independently oracle-verified failure contradicts one unverified positive outcome, can a graph-authored smoothed utility ranking avoid repeating the known-bad first choice better than the current raw-count score?

Use three fresh workers. Each trains the existing graph-authored correction ranker through production `scan_and_self_correct`, retaining its two authentic `CorrectionOutcome` rows. Fork an evaluation state and add one controlled, unverified positive for the known-bad `episode_scoped_offer_guard`. Run the staged recurrence task once under the current policy; capture the candidate's exact independent oracle output. If it fails `[1,0]`, persist that independently verified negative as a branch-local `CorrectionOutcome`. Then fork two matched arms from that state: (a) the current graph rank Program, whose score is structural cost + 100×failures − 10,000×successes; and (b) an experimental graph-authored Program that minimizes `1 - (successes+1)/(successes+failures+2)`, with structural cost as a 1e-6 tie breaker (uniform Beta(1,1) smoothed utility mean).

Each arm evaluates the same recurrence task with the same candidate generator and exact one-offer-per-candidate, fixed-point oracle. Capture program identity, history counts, raw evidence counts, selected candidate, first oracle output, trials to success, adoption, and primary-state parity. The treatment changes only the Program term stored in the evaluation branch. No production default changes are part of this experiment.

**Gates:** three fresh worker processes; production training persists authentic rows; the controlled positive is present before calibration; the current policy selects the bad candidate in the calibration probe and the independent oracle returns `[1,0]`; the verified negative is recorded only after that oracle failure; both matched policies inherit identical evidence and pass the final oracle; the current policy still selects the bad first candidate after the negative is recorded; the smoothed-mean Program selects the candidate-scoped repair and succeeds on its first trial; primary graph/rules remain unchanged; source/native lock is stable.

**Limits:** This is a mechanism test on one authored candidate pair and recurrence task. The positive record is deliberately unverified; the negative is verified by the harness's independent oracle and inserted by the harness. The treatment is an authored confidence-aware scoring Term; it does not learn that policy or its prior autonomously. Beta smoothing is a policy hypothesis, not calibrated probability or natural noise modeling. Three workers do not establish broad robustness or transfer.
