# Evidence selection and diagnosed search contract

**Scope:** P26 design and evaluation contract. This specification selects only the generic repairs supported by P23 and defines a common learner comparison; it does not claim that selection or search improves learning.

## Evidence boundary

Every selector receives the same finite, learner-accessible training opportunity pool, task affordances, primitive actions, memory policy, and shared work budget. The residual selector may rank only current native prediction disagreements, repeated residuals, and verified learning progress. The random selector samples the same eligible pool from a preregistered stream. The fixed selector follows a deterministic ordering over that same pool. Selection never reads a task answer, held-out identity, evaluator archive, or future outcome.

A task opportunity is not learned evidence. The independent world executes an authorized action and returns its typed receipt; the common native learner must ingest the receipt. Record native state before and after delivery and test later behavior on a fresh binding. A receipt, task completion, candidate proposal, or process search attempt alone does not count as a learned-state change. Unlearnable and irrelevant opportunities remain in the denominator and become terminal for the exact evidence key when native progress is absent.

P25 demonstrated retention of an acquired target relation but all arms scored zero on its unseen ButtonWidget transfer task. P26 must therefore report absolute unseen-binding performance and floor/ceiling rates alongside contrasts. A zero loss between floor-level arms is not positive transfer evidence.

## Search identity and finite remedies

Apply only these P23-supported generic changes:

1. Before minting a candidate, compare its exact native effect digest against identity, active, adopted, and previously proposed effects in the same domain and probe context. Preserve syntax attempts and their provenance, but an equivalent effect does not mint another candidate or count as a unique effect.
2. Keep the existing global search ceiling at 120,000 attempts. For the registered bounded Loopover g1 development branch, allocate four target requests at 10,000 ordinary discovery attempts and up to 5,000 independent-goal qualification attempts each. This is at most 60,000 new attempts; with 20,000 inherited attempts the graph remains at or below 80,000. Unused transfer reserve stays unused. Do not reallocate it to discovery and do not count candidate-specific human approval time as search work.
3. An optional attempt-detail export may copy existing native attempt records to an external report only when an explicit CLI flag is supplied. It is read-only, defaults off, and has no path back into agent graph or selection.

Exact equivalence applies only when the finite deterministic effect is fully evaluated under the same domain and complete probe set. Keep partial, stochastic, unknown, and non-comparable effects distinct. Retain each expression, parent, effect, source epoch, attempted-work count, qualification trial, and failure status. Identity, active, adopted, and duplicate effects are ineligible for novelty or improvement. P23's mathematical finite witnesses are not native qualifications; only registered training trials can qualify an effect.

The search comparator receives the same tasks, initial held processes, work ceiling, and evaluator access as the selectors. It cannot receive oracle expressions, solver witness paths, candidate labels that encode recipes, or held-out outcomes. Count repeated syntax, repeated effects, invalid evaluation, exhausted requests, unspent reserves, failed transfer, and all unqualified proposals.

## Worlds and causal measures

Use at least two heterogeneous finite training-world families and generate shared opportunity pools before treatment. The world chooses latent relations and task instances without reading active candidate names. Include learnable, repeated, irrelevant, unlearnable, partial, and transferable relations. Keep exact source receipts and scorer-only solvability labels outside learner input until authorized delivery. Training, development, validation, and held-out namespaces are disjoint and hash-bound.

Measure for each paired stream and arm:

- selected and available opportunity IDs, action/receipt exposure, duplicate and failed opportunities;
- native learned-state delta and whether a receipt changed later predictions/actions;
- success versus fixed cumulative work checkpoints and unseen-binding performance;
- unique verified process effects, exact-equivalence duplicates, proposals, qualifications, adoptions, and their approval costs;
- all attempts, native rule work, shared-budget debit, graph/serialized memory, evictions, and elapsed work;
- missing, pending, failed, floor, and ceiling outcomes without exclusion.

The fixed held-out design uses 200 paired streams per family and capacity/load stratum. The primary learning-curve AUC gain threshold is 0.10 over the stronger of residual, random, or fixed selectors; process-search outcomes are separate and report unique verified effects and later unseen-binding use. No efficacy threshold can be rescued by success in a different outcome. A task-created receipt without changed learned state and subsequent behavior fails the causal mechanism gate.

## Stop conditions and claim limits

Held-out leakage, unequal task-pool access, uncharged answer-bearing state, an implicit action, a weakened approval/novelty guard, or success-selected censoring invalidates the affected estimate. A structurally valid null or negative result remains reportable. This contract does not establish general synthesis, benefit from residual selection, human-equivalent reasoning, or capabilities beyond the measured finite worlds.
