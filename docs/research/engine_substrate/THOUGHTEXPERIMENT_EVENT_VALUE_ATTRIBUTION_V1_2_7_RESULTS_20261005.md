# Thoughtexperiment pre-clone admission and mutation routes v1.2.7 results

Three source-locked workers pass the corrected independent analysis across nine fixtures. Event attribution now estimates bounded recursive payload size before cloning a node or edge before-image; over-budget and over-depth values fail closed without retaining value pairs. Both the 20,000-element collection and a 140-level nested list produce one truncation receipt, zero retained values, and zero counted payload bytes. The object cap retains exactly 512 values/event; the report-object fixture reaches 16,384 values and truncates event 33. Plain/traced/exact parity and replay of complete event sequences pass.

The new edge fixture independently replays two ordered rule events: `edge_relabel` changes `{state: 0}` to `{state: 1}`, then `edge_remove` changes that edge value to absence. Structural payload accounting is 96 bytes for the two edge snapshots, versus 866 serialized bytes for the event JSON. The report-object fixture remains 524,288 structural payload bytes versus 1,652,753 serialized bytes. Peak whole-worker RSS is 268,776–338,180 KiB across setup and all modes. These payload counts are admission estimates, not exact encoded-size or full RSS guarantees. Admission precedes clones for the attribution logger; independent delta observers retain their existing before-image contract and may still clone full values. The original analyzer's sole failed gate is its known direct/deferred target-selection check; the correction passes all checks.
