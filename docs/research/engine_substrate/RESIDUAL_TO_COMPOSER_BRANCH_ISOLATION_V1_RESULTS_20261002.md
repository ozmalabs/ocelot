# Residual-to-composer branch isolation v1 results

The 13-worker source-locked panel passes all gates. Each faulted task outcome is established in a primary navigation fixture, then induction and grounding run on `Substrate.snapshot().fork()`. All four opposite-action cases derive the same `flip_comparison` proposal for `hop_descend_gradient` and pass held-out utility checks. The nine non-inversion, malformed, or underdetermined controls abstain; the absent-target control does not propose.

Every branch changes, confirming that the mechanism's lazy rule installation and induction artifacts remain branch-local. Branch rule-count deltas are 29 for cue-positive/absent-target paths and 24 for abstention paths. The primary full graph, rules, and revision remain identical during branch work. Returning the result adds exactly one `ExperimentResidual` node per worker: every prior node and edge is unchanged, the primary rule store is unchanged, and positive residual nodes carry the serialized candidate rule. The analyzer passes all branch-isolation and outcome gates. Median snapshot fork time is 0.263 ms on this host; no general speed inference follows from this fixture.

The action-vector decoder and its cue vocabulary remain explicitly authored in the harness. This result demonstrates isolation and useful residual return for that bounded mechanism, not substrate-learned cue interpretation, autonomous target discovery, or open-ended self-improvement. The next learning gate should remove the host-derived action-to-cue mapping and test whether substrate evidence can distinguish competing causes and abstain when the cause is ambiguous.
