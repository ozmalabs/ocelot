# Thoughtexperiment event snapshot payload accounting v1.2.5 analysis amendment

The v1.2.5 byte-cap gate fails because the source counter measures cloned outer attribute-vector payload, not the recursive value representation or its encoded size. The `byte_cap` control retained one snapshot with 128 counted bytes while the event JSON measured 218,114 bytes. This is a measurement-definition failure, not evidence that the capture is within its intended byte budget. The raw capture and both analyzer outputs are unchanged. Subsequent gates must bound encoded or recursively represented values before retaining snapshots, with oversized and deeply nested controls, and report serialized event bytes separately. See [results](THOUGHTEXPERIMENT_EVENT_VALUE_ATTRIBUTION_V1_2_5_RESULTS_20261005.md) and [preregistration](THOUGHTEXPERIMENT_EVENT_VALUE_ATTRIBUTION_V1_2_5_PREREG_20261005.md).
