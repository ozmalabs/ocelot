# Thoughtexperiment event value attribution baseline v1 results

## Result

The source-locked capture completed in three distinct worker processes, with all source/native locks stable and ordinary, target-traced, and exact-snapshot modes agreeing on status and progress counts. The independent analyzer passed lock, worker, source-stability, and cross-mode parity checks. The full attribution gate failed: two direct-write fields were uniquely assigned to one progressed event, while the deferred fixture's five changed node attributes were not all uniquely attributable. Two predecessor-node fields and the direct control attribute were unique; three current-percept identity fields each matched 9,998 progressed deferred events. No changed field was left uncovered, but overlapping candidates are retained as ambiguity rather than resolved by fixture knowledge.

The direct fixture reaches fixed point after one progress step. The TrackIdentity fixture reaches its 10,000-step budget in all three execution modes, producing 29,996 events. This does not establish general nontermination; it does show that this repeated-write fixture is unsuitable for treating a whole-settlement before/after diff as a per-event record. The aggregate delta cannot order or separate repeated writes to the same node fields. ## Interpretation and next gate

External whole-settlement snapshots are an adequate value oracle for a unique direct writer, but they cannot substitute for event-local before-images when repeated or overlapping writes occur. The next measurement should use a bounded deferred fixture with a known single write per target or add native event-local before/after snapshots, with an explicit event-object cap and truncation count. The current capture should remain as negative evidence for aggregate reconstruction; do not treat the 10,000-step budget as a termination result.

This probe does not identify minimal causes, show causal necessity, remove host-authored action/candidate mappings, estimate natural-task frequency, or measure production tracing overhead. The 32 MiB raw file retains the repeated event history behind the reported ambiguity counts.
