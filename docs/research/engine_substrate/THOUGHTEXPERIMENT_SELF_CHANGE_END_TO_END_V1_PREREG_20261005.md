# Graph-native self-change end-to-end repair v1 (preregistration)

Question: can the existing self-change pipeline generate a candidate from measured signals, test it against no-op/placebo arms in isolated native branches, select it through graph proof rules, canary it on distinct examples, and commit the rule edit through Rust CAS?

Three fresh source-locked workers each run the exact `self_change_reasoning` seed under both full-copy and shared-graph-page CoW rehearsal, counterbalancing backend order. The substrate starts with a one-edge target rule whose `where` is false and a simple task objective: mark `TaskOutput` when its paired `TaskInput.signal` passes the learned threshold. A `FaultProbe` receives false-negative and threshold-sensitivity measurements, the common candidate vocabulary, a false live clause, and target UID 0 (no live target identity). The graph rules are expected to generate the threshold adjustment candidate. The harness applies that generated clause to isolated branches and measures distinct training inputs `[1,0]`; no-op and placebo branches use the same inputs. It converts exact task outcomes into `TrialEvidence`, then lets native graph rules apply control-margin, invariance, budget, replication, and MDL gates.

After selection only, the harness binds the selected `RulePatch` to the live rule's UID/revision/hash for mechanical CAS execution. The selected candidate is rehearsed on a disjoint canary input set `[2,3,4,-1,-2]`. Only a full pass permits `CanaryEvidence`; the native graph then requests and commits the patch. Final verification uses previously unseen inputs `[5,-3]`. Three workers must match the expected candidate outputs, no-op/placebo failures, selection, held-out canary, one revision increment, committed receipt, and final outputs. Training, selection, canary, commit, and final-verification costs are captured separately.

This is one authored threshold task and one built-in hypothesis family. Threshold-sensitivity remains an input signal; candidate grammar and task oracle are harness-authored. The experiment does not show target/cue-free discovery, broad proposal search, natural-task utility, or autonomous self-improvement. Its purpose is to test whether the proof/canary/CAS path can consume a graph-generated candidate and real branch outcomes end to end.
