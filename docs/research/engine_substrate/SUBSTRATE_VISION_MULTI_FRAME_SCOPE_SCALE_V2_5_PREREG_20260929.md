# Vision multi-frame scope scale v2.5 preregistration

## Question

How do rule matching and Term-evaluation costs scale with the size of one visual settling frame and with the number of unrelated sibling frames in the same substrate? Does root-scoped `st_settle` preserve each frame's independently calculated update as global distractor frames are added, including when sibling states differ?

This is a second-family follow-up to the live `describe_scene` Percept × Concept factorial. It extends, rather than replaces, the two-sheet `st_settle` scale evidence: the earlier panel reaches 8,192 SUnits but fixes the number of sheets at two.

## Workload and design

Use the source-authored `st_settle` rule, its two-sheet root-scope rewrite, and an independent equation oracle. Construct disjoint, row-major SUnit lattice frames under separate `World` roots. Each frame has local `sunit_neighbour` edges. Exactly one frame is the target. Add zero, one, or two sibling frames of the same size; sibling frames have either the target's initial activation (equal-state control) or zero activation (contrasting-state contamination condition). All afferents are generated by a locked deterministic seed. Each SUnit belongs to exactly one root.

Cross side lengths 16, 32, and 48 (256, 1,024, and 2,304 SUnits per frame) with sibling conditions `(0, none)`, `(1, equal)`, `(1, contrasting)`, `(2, equal)`, and `(2, contrasting)`. This yields 15 registered workload cells. Run each with three deterministic seeds, global and root-scoped rule bodies, and counters disabled/enabled in isolated fresh processes: 180 factorial workers. The maximum graph has three frames and 6,912 SUnits, below the prior v2.4 8,192-SUnit measured envelope.

The candidate global rule reads all SUnits for its competition mean. The scoped candidate reads only the matched root's `has_sunit` members. Score both against independently computed equations: the global equation uses the population across all frames; the frame-local equation uses only each frame's own SUnits. Report both outcomes, so equal-state parity and contrasting-state contamination remain visible without assuming that a scoped rewrite is semantically correct by definition.

## Controls and measurements

For every worker, record candidate tests, total and per-rule Term evaluations, Term-source item counters, closure applications and cap status, equation residuals for every frame, updated-node coverage, per-frame graph digests, closure wall/CPU time, peak RSS, and source/runtime fingerprints. Counter-off and counter-on runs must have exact graph and output parity. Source hashes must match at worker start/end and after the full run. Report global and scoped work separately by frame size and sibling condition; timing remains descriptive.

At the smallest target size with one contrasting sibling, add four membership-omission diagnostic workers (global/scoped × counter-off/on) that remove one target-frame `has_sunit` owner edge while retaining the SUnit node and its local lattice edges. The independent oracle and update-coverage check must identify the omitted member and any induced change to the remaining target outputs. This is a deliberate negative control, not part of the clean factorial estimates. Total scheduled processes: 184.

## Gates

1. Exactly 180 complete registered factorial workers plus four registered omission diagnostics, unique PIDs, complete factor combinations, stable source/native fingerprints, and no output overwrite.
2. Exact disjoint frame memberships, expected SUnit counts, connected row-major lattice edges, and deterministic initial states.
3. Independent global and per-frame equation residuals at most `1e-12` for all applicable outputs; report where each rule variant agrees or disagrees with each equation.
4. Exact counter-on/off semantic and graph parity, counter conservation, no cap exits, and no dropped instrumentation rows.
5. Repeated counters, outputs, and graph digests across three seeds only where the deterministic inputs imply identical graph/work; stochastic-afferent fields are seed-specific and compared to their own oracle.
6. The omission diagnostic detects the missing owner and does not silently pass as complete frame coverage.

## Claim boundary

This tests a synthetic visual-domain rule over declared lattice frames. It does not run image ingestion, full visual learning, natural visual tasks, or an automatic frame learner. The root-scoped form is a benchmark candidate, not an assumed production policy. Results do not establish general learned cheap-cut locality, asymptotic complexity for arbitrary rules, or a natural distractor distribution.

## Reproduction

The capture runner and independent analyzer will be source-locked before execution. The full seed, native extension/build identity, relevant Python builder closure, `vision_settle.json`, and this protocol are hashed. Each worker is independently runnable from its registered factors. Preserve incomplete or source-drift captures as censored artifacts; do not merge them with the confirmatory aggregate.
