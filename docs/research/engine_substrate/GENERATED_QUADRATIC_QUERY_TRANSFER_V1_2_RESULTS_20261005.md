# Generated quadratic query-transfer v1.2 results

The fresh 120-cell replication passes all eight analyzer checks. Both coupled-quadratic scalar functions produce two fitting hypotheses, including one exact held-out term. Maximum entropy picks a separating input in one label for all 20 permutations per task and retains the exact term in every run. Fixed-first averages 1.2 labels for the first component and 1.3 for the second; seeded random averages 1.1 and 1.2. All three policies have a median of one label, so the improvement is concentrated in the slower permutation cases.

The independent analysis reports synthesis at 8.91 ms wall / 8.91 ms CPU for the first component and 13.66 / 13.63 ms for the second. Entropy decisions take 0.381 and 0.572 ms median, with 72 native Term evaluations; fixed-first and random take 0.012 and 0.016 ms with two evaluations. On this finite synthetic-oracle task, the modest reduction in labels costs substantially more local computation. These figures are one-host harness timings and not a natural-task or system-scale estimate.

This confirms the narrow synthesis-to-query integration: generated terms can be filtered by actual query labels while retaining a held-out-exact program. It does not show substrate-directed grammar choice, query-domain discovery, oracle reliability, graph-resident version-space management, broad learning prevalence, or self-modification. The 20 permutations per task are not independent task samples.
