# Attribute-site active-choice v1 analysis amendment

Two analysis defects were caught after capture, with no changes to the locked runner, preregistration, lock, frozen orders, or score data. First, the initial analyzer treated the JSON-serialized prediction list as a mapping; correcting iteration allowed review to run. Second, the preregistered one-bit entropy threshold is impossible for three hypotheses with binary predictions: the most balanced partition has group sizes 1 and 2 and entropy `log2(3) - 2/3 = 0.918295834` bits. All 32 selected queries have exactly this partition and reach that mathematical maximum. The corrected analyzer uses that attainable bound. The current analyzer hash therefore differs from the analyzer hash in the lock; results should be cited as a locked runner/order/score capture with a disclosed post-capture analysis correction, not as a locked analyzer replay. The original literal one-bit criterion is not met; it is invalid for the preregistered three-hypothesis setup.

During the independent raw review, the held-out gate was also split into separate fault and reverse-candidate failures rather than accepting either failure as sufficient. Both candidates fail a nonzero held-out in every worker; the forward candidate passes all held-outs. This strengthens the interpretation check and is included in the final 14-check review. It changes only analysis code, so it shares the analyzer-hash limitation above.
