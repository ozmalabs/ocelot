# Browser seed ReachableFrom cache panel v1 results

**All preregistered gates pass.** The panel loaded both rules directly from the current `browser_affordance_reach` seed and ran 24 fresh workers: three repeats over N={2,8,32,128} affordances and B={1,4} top-level wrappers. Source, seed, engine build, and native binary remained locked and current.

Every run reached fixed point and emitted exactly N `has_affordance` mirror edges. Within every worker the cache arms had identical final graphs, progress counts, runtime access-trace rows, and zero dropped trace events. Matcher counters (`cand_tested`, `where_evals`, `rule_enumerations`) matched. The independent analyzer passes all eight integrity and semantic checks.

The authored rule repeatedly asks whether each affordance-bearing element belongs to `ReachableFrom(sess, "contains")`. At N=128, the measured `ReachableFrom` adjacency work fell from 2,097,280 to 257 visits with B=1 (8,161×), and from 587,776 to 260 with B=4 (2,261×). Cache-arm medians were 72.4 ms and 23.1 ms, versus 186.0 ms and 59.1 ms off; wall time is descriptive and includes scale and access-trace instrumentation. At the smallest N=2, B=1 cell, work only falls 10→5, showing setup and the extra fixed-point pass can dominate at small scale.

This measures the actual source-authored seed rules on DOM-shaped synthetic graphs, not a live BrowserWorld page or the natural distribution of page sizes and shapes. Source inspection also limits the intervention's current reach: the setter toggles the substrate-owned cache used by rule rewriting, while `PySubstrate.evaluate` creates a new default-off `EvalCache` per direct call, and the higher-level Python `Substrate` wrapper has no setter. Thus direct `grounding_reach` / frozen-seed closure queries do not benefit from this option. Cache memory and all mutation invalidation routes remain unmeasured. The next step is an active-path census plus explicit API/cache-lifetime design, followed by resource and invalidation gates ([preregistration](SUBSTRATE_BROWSER_REACHABLE_CACHE_V1_PREREG_20260928.md), [runner](../../../scripts/substrate_browser_reachable_cache_v1.py), [analyzer](../../../scripts/analyze_substrate_browser_reachable_cache_v1.py), [raw capture](../../../evaluation/reports/substrate_browser_reachable_cache_v1_20260928.json), [analysis JSON](../../../evaluation/reports/substrate_browser_reachable_cache_v1_analysis_20260928.json)).
