# Bigville dynamic-link cut capture v1 preregistration

**Date:** 2026-09-26. This is a source-current structural capture extending
the previously accepted dynamic-link mutation design. Its ring, star, seeded
random-connected topology generator and seven mutation checkpoints match the
older locked probe. The old probe remains evidence for caller-queue parity and
omission sensitivity; this capture adds complete graph snapshots, native
endpoint identities, current source fingerprints, and per-checkpoint cut
recomputation.

## Design

Run three fresh replicates for each of ring, star, and seeded
random-connected 100-frame Bigville topologies. Each worker builds the native
CAN substrate from the current frozen builder/seed, derives 100 five-Concept
frames from live ownership and causal components, then executes the frozen
sequence: baseline; insert cross-frame links; apply the existing ten-resident
evidence update; delete one third of injected links; reweight the rest; reinsert
deleted links; remove all injected links. Use monolithic full closure as the
semantic oracle at each checkpoint and independently recompute the CAN
residual from stored node states, fields, directed edge weights, and threshold.

At every checkpoint capture the complete typed graph, owner map, active dynamic
link endpoints, trace rows/drop count, closure counters, exact graph digest,
mutation and closure timing, and residual. Recompute three deterministic
partitions: authored ownership; sorted native-ID groups matching authored
sizes; and contiguous authored-size groups from min-fill order over all
non-ownership typed task-to-task edges plus observed task-to-task access pairs.
Report all typed crossings, global boundary edges, within-authored-pair
retention, min-fill width, and reconstruction CPU/wall costs separately.
Treat traces as partial and retain every captured typed edge in the
conservative graph.

Use the existing benchmark's complete all-owner closure oracle: repeated
round-robin settlement of every frame's Microtheory scope until a no-progress
round. This is the accepted Bigville full-sweep policy, not the unscoped
`run_rules_report` API. The independent global CAN residual remains the
semantic check.

The active CAN rule's `reads_any` flag requires all alternative scoped
executors to return `refused_wildcard_rule_access` before making a scoped call.
This gate measures cuts and the reason they cannot safely be executed; it does
not turn a refusal into parity. The old dynamic-link study's full/event/omitted
results remain separate evidence and are not merged into this capture's fresh
worker counts.

## Outputs and interpretation

Lock all code/data/native inputs before workers start; require three distinct
workers per topology, source stability, full fixed points, zero independent
residual, and independent recomputation of graph digests, mutation states,
partitions, and costs. This generated structural panel is not a natural-task
prevalence sample and provides no candidate-partition speed result. A later
integration must use the complete dependency contract or refuse, preserve the
omission control, and include discovery/maintenance cost.
