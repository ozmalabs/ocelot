# Full-seed GenMint held-out transfer analysis amendment v1.1

**Amendment date:** 2026-09-26, after v1 capture and initial analysis. The held-out fixture has two relations, so a held dimension already in the full seed (for example `scale2`) can explain some held-out observations. The v1 analyzer scored any transform whose generator name matched a linear generator, and treated missing linear-generator scores as zero-correct rows. That denominator conflated failure to reuse the newly acquired linear generator with recognition through another held dimension.

Preserve the raw v1 capture and initial v1 analysis unchanged. The amended analysis classifies each held-out route as: (a) transform references the newly acquired expected linear matrix, with rows independently scored from that generator and residuals; (b) transform references another generator, reported as an alternate held-dimension recognition route and excluded from the acquired-generator accuracy denominator; or (c) no transform, reported separately. The preregistered clean-training/clean-heldout positive gate specifically requires use of the expected acquired linear matrix and exact held-out rows. Other cells remain descriptive. This is a post-capture scoring correction, not a new confirmatory experiment.
