# Learned numeric cue to composer integration v1 preregistration

Date: 2026-10-03

## Question

Do the frozen Term ASTs learned in the coverage-directed numeric relation
study execute inside a native residual rule and drive the existing structural
composer to useful held-out repairs in isolated Thoughtexperiment branches?

## Frozen inputs and design

Use all five learned Terms from the source-locked coverage-directed relation
learning capture. Do not resynthesize, simplify, edit, or select among them
after seeing integration outcomes. Embed each AST in a native graph-rule
`where` condition by mapping its four variables to the raw residual's numeric
displacement attributes. Cross each of the five Terms with the frozen 13-case
navigation panel (65 fresh-process cells): four opposite-direction positives,
eight ordinary controls, and one target-absent positive-residual control.

The rule's learned component is only the synthesized boolean Term. The
following remain authored evaluation wiring: numeric-vector encoding of task
actions, the association from a true relation to the existing cue vocabulary,
and the existing cue-to-edit/composer path. Candidate branches receive the
learned rule; baseline branches receive no cue rule. Both fork the same primary
snapshot. Score positive proposals in a fresh held-out navigation context.

## Gates

- All five learned Term digests match the frozen learner capture and all 65
  rule `where` trees contain the exact attribute-bound learned AST.
- Across 20 ordinary positives, the rule derives the cue, the composer builds
  `flip_comparison` for `hop_descend_gradient`, and all held-out outcomes pass.
- Across 40 ordinary negative controls, no cue or proposal is emitted. In the
  five target-absent controls, the cue may derive but no proposal may build.
- Baseline branches make no proposal; no action-pair codebook is present; the
  primary graph/rules/revision remain unchanged until one compact residual
  receipt is returned.
- Source/native hashes remain stable; report acquisition, induction,
  composition, scoring, and branch costs separately.

## Interpretation

Passing demonstrates an end-to-end supervised-learning-to-native-execution-
to-composer path for one fixed relation, five training draws, and one authored
task family. It does not show autonomous task discovery, unsupervised label
acquisition, cue-vocabulary invention, or learning which operator to apply.
