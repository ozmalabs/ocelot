# Phase 5 mechanism evaluation addendum v3

**Protocol:** `cognition_p5_mechanism_eval_v3`
**Status:** draft; freeze this addendum alone after self-checks, focused suites and development-panel checks pass.
**Supersedes for decisions:** v2 is retained as a historical run, but its E4 comparison is NOT_ESTABLISHED because the one-step arm used a depth shortcut rather than inspecting the shared transition graph. V1 remains an honest NOT_ESTABLISHED harness run (`0826089af64c38da3c34d3be2c96ca490364ffa3`). V3 reruns every family under a new hash and seed.

This addendum executes the original P5 held-out criteria through each shipped graph/native mechanism. It uses a new preregistration hash, seed derivation, and report namespace. The registered case counts and decision thresholds remain unchanged: 200 paired primary cases and 100 paired controls per item, with max 64 epochs, planner depth 8 and 256 expansions. Exact McNemar tests are reported for paired binary comparisons, Wilson 95% intervals for binary rates, and paired bootstrap 95% intervals from 10,000 deterministic resamples for work differences. Holm correction at family-wise α=.01 applies to the three superiority tests F2, G2 and E4. A new registered draw is permitted only after the standalone freeze commit and before inspecting any v3 outcome report.

The runner supplies each arm only its generated input. Scoring oracles stay in a sibling report field and are not copied into substrate nodes. F1 projects four distinct normalized source records, rotates owner/holder assignments, and scores row provenance, source preservation and belief/truth separation. F2 uses unseen holder names, second-order paths and accessible true/false queries; adverse controls remove accessibility, and every case separately snapshots an ActualWorldFact. G2 runs the funded reappraisal seed with matched arousal; supported cases retain evidence edges and adverse controls remove support. G3 instruments the native reflex sink across timely stop, valid go and late-stop schedules. E3 evaluates finite confounder, collider and chain models through native `SCMIntervene`; nonidentified controls must return unknown. E4 runs the bounded graph planner over versioned transitions with depth 2–8, trap loops and missing-edge controls, follows linked path arrivals, and checks the resulting actions against a separate deterministic environment. The one-step arm receives the identical edge list, directly checks whether a start-to-goal transition exists, and independently executes that one edge; a development fixture with an added direct goal edge must succeed. A2 runs graph completion across all partial key counts, complete primary cases and stale-epoch controls. D6 samples distinct four-point lattice shapes and angles 0/90/180/270, runs funded graph-native incremental rotation, and then tests primary cases with a matching request/source-bound verifier receipt. Every D6 control instead supplies a verified receipt bound to an unrelated source observation; the request must remain unresolved and ungrounded. The direct-exact arm remains an evaluator baseline. Imagery remains ungrounded in both arms.

Primary criteria are inherited from the P5 detailed plan: F1 ≥95% exact conformance with zero leaks/source loss; F2 ≥80% accuracy and ≥20 percentage-point gain with corrected p<.01 and no actual-world overwrites; G2 ≥20-point supported-appraisal gain with corrected p<.01 and no source edits/unsupported acceptance; G3 all timely stops withheld, ≥95% valid go emissions and no duplicate emissions; E3 ≥95% agreement on identified cases and unknown on unsupported cases with no live-graph mutation; E4 ≥20-point observed solve gain for depth 2–8 with corrected p<.01 and no unsafe emission/false grounding/bound violation; A2 100% valid completion decisions and no premature settlements; D6 ≥95% exact verification, no grounding, and actual transform work reported. Missing observations, timeouts and adapter errors remain null and block a PASS.

Development self-checks use draw indices above the registered 0–199 range and a separate development seed. They assert that each arm returns a structured result, that a direct one-step goal edge is actually detected, that a mismatched imagery receipt is rejected, and that no scoring oracle enters agent input. Adapter exceptions are recorded as null outcomes with error details and block a PASS. Artifact hashes cover this addendum, both v2 archive scripts, v3 runner/analyzer, native binary/build metadata, mechanism seeds/generators and adapter fixtures. Registered reports remain uncommitted.
