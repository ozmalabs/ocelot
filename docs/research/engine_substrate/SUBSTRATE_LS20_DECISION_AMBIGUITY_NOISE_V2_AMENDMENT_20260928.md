# LS20 decision ambiguity/noise v2 analysis amendment

The original v2 run completed all 640 preregistered worlds under a stable source/build/input lock. Its first independent analyzer failed two gates because the analyzer's operator-balance check counted only the broad family labels (`rotate`, `reflect`, `recolour`) and therefore collapsed the six parameterized operators. The runner had scheduled all six variants; this correction independently counts `rotate:1/2/3`, `reflect:c/r`, and `recolour`, while separately checking the runner's family label. No task outcomes, scenario conditions, or source inputs are changed. The original capture, original execution lock, and initial analysis with its false-negative gates are retained. A separately named corrected analyzer and audit lock hash the amendment, corrected analyzer, capture, original worker lock, and initial analysis. Worker source-lock gates continue to be evaluated against the unchanged v2 execution lock.
