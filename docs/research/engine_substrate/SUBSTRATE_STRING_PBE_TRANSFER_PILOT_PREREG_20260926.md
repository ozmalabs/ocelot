# String PBE transfer pilot preregistration

**Status:** locked before the benchmark run. This is a bounded capability pilot, not a confirmatory estimate of natural task performance.

## Question

Can the current P4 request-to-program route apply held string-processing structure to fresh inputs and constants, across unary operations, parameterized operations, and a two-step composition, and does the frozen learned-layer arm change exact held-out performance?

## Frozen workload

The generated 24-task suite covers six registered strata: character replacement, delimiter split, substring count, suffix append, prefix prepend, and casefold-then-suffix. Each task has four revealed and three held-out examples, produced by a deterministic per-task RNG rule. The target transformations are simple deterministic functions used only to generate expected outputs; the benchmark provides examples and requests to the system. The operation templates overlap the engine's existing string grammar, so this measures fresh-constant/instance generalization within a supported operation family, not discovery of unknown operators.

The fixture is `tests/fixtures/substrate_string_pbe/tasks.json`, generated by `tests/fixtures/substrate_string_pbe/build_tasks.py`. Its SHA-256 is recorded in the execution lock.

## Arms and outcomes

- **Main:** current P4 full route and current seed/codebook.
- **Frozen:** same route with the benchmark harness's frozen learned-layer setting; exemplar retrieval remains available.
- **Main replay:** independent fresh substrate rerun of each main task to check deterministic outcome/read-back parity.

Primary outcome is exact correctness on all three held-out rows per task, under the existing P4 scorer. Report accepted-but-wrong tasks, gaps, rung/construction paths, retrieval and enumeration attempts, candidate counts, route and boot time, wall time, and peak process RSS. Compare main and frozen by paired task outcomes with family-stratified bootstrap intervals; do not interpret a zero difference as equivalence. Require exact task-by-task main replay fingerprints. Any failure remains in the report.

## Interpretation limits

The suite is generated and narrow; its examples are not sampled from a natural workload. The operation set is already supported. Retrieval may solve tasks from held exemplars, so accepted retrieval is evidence of template adaptation, not new structure induction. Results cannot establish general string understanding, unseen-operator learning, natural distribution frequency, transfer beyond these six strata, or commodity-scale tractability. No task, example, budget, grammar, seed, or scoring rule will be changed after the lock; any repair requires an amended preregistration and separate result.
