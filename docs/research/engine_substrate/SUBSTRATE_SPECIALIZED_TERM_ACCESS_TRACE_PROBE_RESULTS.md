# Specialized Term access-trace probe

**Run date:** 2026-09-26  
**Evidence grade:** twenty-four targeted direct graph-read probes with paired semantic controls  
**Status:** all expected event families were observed; traced/untraced runs matched and settled; static access checks pass after correcting one discovered extractor omission.

## Probe coverage

The paired fresh-substrate fixtures exercise `SlideNeighbours`, fallback-scan and declared-index `NodesWhere`, `NodesOfType`, `ScalarAttrTriples`, dynamic-key `AttrByName`, `Edges` composed with `EdgeAttr`, Huffman table decoding, renderer subgraph traversal, recursive `LookaheadValue`, all three Enigma Terms, `TrackIdentityCorrespondence`, two-step `NetForward`, supported `FutureManifoldProjection`, candidate-family `FutureManifoldSelection`, minimal `MotorCompose`, successful `TransformDecode`, generator-backed `DimInfer`, and `GenInfer` at two coordinate scales plus a mint/redecode integration path. The indexed fixture declares `(Probe, flag)` after node insertion, exercising index backfill before the Term runs; the runner verifies `has_attr_index` on both paired arms. Each run is checked for fixed-point settlement and equal progress under trace-off and trace-on conditions. TrackIdentity checks one correspondence, NetForward checks its exact output, projection resolves, selection checks the lower-intervention candidate, MotorCompose checks paired boolean parity; TransformDecode reports `explained = 1.0` for a single-relation delta, and DimInfer reports `explained = 1.0` for the held rotation90 orbit. GenInfer returns `[2,1,1,1]` after checking 6,560 matrices; doubling the coordinates preserves that normalized matrix and checks 83,520. In the integration fixture this matrix is inserted as a `DimensionGenerator` node and DimInfer successfully selects it to decode the same target.

All gates pass across twenty-four cases, including explicit indexed and fallback `NodesWhere` routes. TransformDecode records one scanned `EvidenceAxisSample2D` node and its `name`, `signature`, and `dim_types` attributes, then returns the expected result in both arms. Shape-decode's shared scan hook also covers generator, cue, mechanism, registry, metashape, and observation loops at source sites. The TransformDecode path observes one codebook node; the DimInfer path observes one codebook node and one generator node. Each GenInfer trace records one ShapeSignature candidate and five of its attributes. Candidate counts are 6,560 at the first scale and 83,520 after doubling coordinates; the latter count is consistent with enumerating all non-identity matrices in `[-B,B]^(2x2)` at B=8. The integration fixture verifies output-to-generator-node-to-decode semantics, but inserts the node through the direct API; that insertion and the direct DimInfer calls are outside rule tracing. A fixed value-noise control returns `explained = false`, an empty matrix, and 624 checked candidates in both arms. This is one null control, not a noise-distribution study. The fixtures confirm semantic composition and candidate counts at two points, not automatic mint-rule behavior, latency, or asymptotics beyond the documented formula. The MotorCompose fixture records seven attributes and one adjacency edge; FutureManifoldSelection records 16 attribute reads plus type scans. These are selected paths, not complete helper footprints. There are no drops. Event resources are checked against `rule_access_sets()` including wildcard flags.

The first run surfaced a static access bug: `ScalarAttrTriples` scans arbitrary live nodes and scalar keys, but `derive_access` had neither keys nor `reads_any`. `collect_term_reads` now marks this Term as wildcard-read. The corrected run has no static mismatch. This is a concrete example of why the frame-locality measurement needs both dynamic traces and static access audits.

## Limits and next work

These are direct-site probes, not a frequency sample of natural workloads or proof of complete access-footprint coverage. `EdgeAttr` records source, key, and target but does not encode edge type in the bounded event tuple, so its concrete edge identity is not suitable for writer-reader pair inference. MotorCompose's minimal fixture does not exercise humanoid fallback, basin traversal, or rich model paths. FutureManifoldSelection's generic projection path is covered, but domain fallback selection and snapshot variants remain open. TransformDecode and DimInfer cover only one selected codebook/generator path each; ShapeDecode composition remains open. GenInfer has two positive 2-D scale points and one output-to-node-to-decode integration fixture, but no broader negative/noisy controls, robust runtime scaling study, automatic mint-rule integration, metashape, or observation-group paths. Candidate frames must still be tested against monolithic closure plus omitted-boundary controls.
