# List PBE pilot preregistration (2026-09-25)

**Protocol:** list-pbe-v1; **state:** pilot; **claim class:** mechanism-envelope estimate, not confirmatory.

## Frozen suite and question

The suite contains 22 deterministic integer-list tasks, each with four revealed examples and three held-out examples. Categories are five reductions, three projections, three maps, three filters, four compositions, one one-off composition, one adversarial underdetermined task, and two declared-inventory out-of-inventory controls. The tasks and reference outputs are generated by `tests/fixtures/substrate_list_pbe/build_tasks.py` and frozen in `tasks.json`.

The question is whether direct native `SynthEnumerate`, given only revealed examples, finds a program whose output is exactly correct on all three held-out inputs under a fixed search budget. This is a small fresh list-transform family pilot; it does not measure residual routing, concept minting/adoption, natural task prevalence, or general transfer.

## Conditions and budgets

Each task is run once in each condition, in a fresh native `Substrate`:

1. `typed_default`: the synthesizer's native typed-default grammar.
2. `fixed_declared_list_grammar`: the exact operator and constant lists embedded in the raw report and pilot harness.

Both conditions use `max_size=15`, `max_candidates=200000`, `saturate_k=0`, identical revealed examples, and the same evaluator. Condition order alternates by task ordinal. There are no retries, escalations, tuning, cross-task memory, prompts, or mint/adoption steps. Results are paired by task.

## Outcomes and analysis

Primary endpoint: task passes only if a found program exactly matches all three held-out outputs. Report numerator/denominator and descriptive Wilson 95% intervals by condition. Secondary outcomes: found-but-held-out-fail, not-found/halt reason, tested/distinct candidates, search time, holdout-check time, and resource use. Report task-paired pass patterns and category strata. These small pilot intervals are descriptive and do not license population claims. Candidate count and time are measured per attempt; no cost amortization is inferred.

The two “out-of-inventory” controls are outside the fixed declared operator inventory. The typed-default grammar may include additional operators, so these are not guaranteed negatives for that arm. The degenerate last-element task deliberately makes first and last extensionally equal on revealed examples; held-out inputs distinguish them.

## Freeze and deviations

Before execution, the lock record `evaluation/substrate_capability/list_pbe_pilot_lock_20260925.json` records hashes for the generator, task file, harness, this preregistration, benchmark protocol, synthesizer source, value codec, PBE wiring, Cargo lock, and installed native extension. The exact invocation and runtime provenance are stored in the raw report. Any instrumentation correction after seeing outcomes must be documented; it cannot silently replace this pilot result. No confirmatory claim is made.
