# Graph-native blind self-change baseline v1 (preregistration)

Question: given observations, candidate edit representations, and measured candidate/no-op/placebo outcomes, does the graph-native self-change pipeline select the minimal proven candidate and abstain when no candidate beats controls?

Run all seven cases from `tests/fixtures/self_change_blind_faults.json` through the exact `seeds/self_change_reasoning.json` rules in three fresh source-locked workers. The runner will not import the test module or its hidden `EXPECTED` mapping. It will replace case IDs with opaque IDs, ingest only each case's signals and common candidate-clause vocabulary into `FaultProbe`, let native rules create `SelfChange` and candidates, then ingest measured candidate/control outcomes. The harness independently derives admissibility after the decision using the seed's explicit thresholds: candidate gain must exceed both no-op and placebo by more than 5, protected regressions must be zero, resource cost must fit budget, and at least two replications must reproduce gain ≥5. For each selected patch, compare against the minimum `mdl_cost` among admissible candidates; for the correlation-only case require no selection and a graph-authored abort after the evidence batch closes.

Report all candidate families, selected family, admissible set, MDL costs, proof state, abort reason, and timing. Check that no answer-key field reaches the substrate and that each case uses a fresh substrate. This is a graph-native selection/proof-gating result conditional on host-authored candidate representations and measured outcomes. It does not evaluate candidate invention, causal measurement acquisition, real target identity, clause correctness on an external task, rule adoption, or self-improvement.
