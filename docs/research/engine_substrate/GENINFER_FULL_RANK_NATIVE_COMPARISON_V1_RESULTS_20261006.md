# Native full-rank GenInfer comparison v1 results

The feature-enabled native evaluator acquired the registered 1-D and 3-D matrices through the normal graph closure and minted `DimensionGenerator` nodes. Both were reused on held-out observations, which produced `recognized_transformed` receipts. The feature-off binary did not acquire these higher-dimensional generators. The existing 2-D arm preserved its generator, receipts, residual, status, and closure-work projection exactly across binaries.

The 3-D rank-deficient training and held-out controls abstained, as did both nonlinear 3-D phases. Full-rank audit counters reconcile at every phase: `bases = refusals + attempts`, and attempts equal the sum of apply, candidate, residual rejections, and survivors. The capture contains 20 source-stable workers over five fixtures, two binaries, and audit on/off. Representative audit-off training/held-out times were 1.55/0.79 ms for the 3-D solver path versus 0.84/0.67 ms in the feature-off control; the new path adds work but supplies the missing capability. Each cell has one worker, so the timing is descriptive only.

The independent analysis passes after correcting its baseline-arm check and tightening the rank-deficient fixture to remain underdetermined through held-out evaluation. Because that analyzer correction followed the capture, retain the initial failed analysis as a diagnostic and classify this analysis as post-capture, not preregistered confirmation. The next gate is a fresh preregistered replication with corrected analysis locked before workers run, more replicates, explicit malformed/ambiguous-ID controls, and exact matrix/receipt checks across more full-rank geometry families. This does not establish natural prevalence or rank-deficient induction.
