# GenInfer fused candidate validator v1 results

The paired comparison passed all analyzer gates across 88 fresh workers: 22 registered tasks, two source-matched binaries, and audit-on/off runs. The baseline and experimental fused validator produced identical training, transfer, held-out, corruption, generator, residual, receipt, and closure-work projections. GenInfer attempt counters reconciled to the registered bound formula in every audited phase, and each worker retained stable source and binary provenance.

The optimization did not change measured search or term work. Audit-on `term_unit:GenInfer` counts are identical between arms for every task and phase, including 23,437,440 units for each coupled-quadratic transfer. For the fullseed positive cells, audit-off training median fused/baseline ratios are centered at 0.997 (18 task cells; range 0.692–1.044). The wide per-cell range and near-one median provide no reliable speedup signal. Held-out and corruption phases are similarly centered near parity. One host and two authored workload families limit inference; the feature remains experimental and disabled by default.

This gives no work-reduction theorem or implementation result for the wider tractability program. The useful finding is that candidate-validator loop fusion can be gated behind a feature with exact bounded behavioral parity, but this implementation is not yet an optimization. Next profile the candidate path by phase and rejection point to find avoidable traversal or allocation work, then test a revised candidate only if it reduces a direct work counter and preserves these semantic controls. Keep higher-dimensional inference, frame-boundary complexity, and natural workload prevalence as separate open gates.
