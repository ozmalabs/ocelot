# Edge-matched degree-profile inference v1 preregistration (2026-09-29)

## Question

At fixed node count, edge count, and certified treewidth, how does concentrating degree on a small hub set change exact junction-tree MAP cost and its elimination-profile proxies?

## Design

Compare three binary pairwise topologies for q in {4,5,6}, N=120, and six deterministic replicates per q/family (54 fresh workers): the existing q-wide grid, existing sparse partial q-tree, and a new hub-concentrated partial q-tree. Each cell has exactly the grid's edge count and a supplied elimination certificate of width q. The hub family begins with a (q+1)-clique, then connects each later vertex to one persistent hub and allocates the remaining edges to a concentrated prefix of vertices, always using subsets of that core clique. Thus its width-q certificate is constructive and its degree concentration is manipulated while N/E/q remain matched.

Use the existing locked edge-matched inference worker for extraction, deterministic factors, min-fill and certified-order JT MAP, independent factor-table variable-elimination oracle, direct rescoring, no-mutation check, timing, traced allocation, and elimination bag/separator/child profiles. Record degree quantiles, maximum degree, and a normalized degree Gini coefficient. The main descriptive comparisons are runtime and profile work across families; there is no latency pass threshold.

## Integrity gates

Require all 54 workers, six per cell; exact N and E matching; certificate width q; exact runtime extraction; both exact MAP energies and direct assignments matching the independent oracle within 1e-8; unchanged graph state; valid pre/post source lock; and complete degree/profile fields. Any violation invalidates the affected run; do not silently discard workers.

## Scope

This is a controlled synthetic topology experiment. The hub graph is generated by a known clique-separator construction; it is not a naturally observed task distribution and does not measure learned frame discovery. It isolates degree concentration conditional on bounded treewidth. Results do not establish asymptotic runtime or natural-world tractability.
