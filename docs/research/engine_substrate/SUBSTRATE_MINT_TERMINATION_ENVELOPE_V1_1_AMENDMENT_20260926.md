# Recursive mint termination envelope v1.1 amendment

This amendment preserves the preregistered fixture, arms, sizes, repeat count, budget, and interpretation rules. It adds a pre-run source lock, the shared `substrate-run-manifest-v1`, a captured parent console log, and an independent analyzer. The amended replay runs against the current source/native build and writes to a separate report; it does not overwrite the 2026-09-25 diagnostic.

The experiment remains a finite capped comparison of one recursive rule shape. `progress_budget_reached` is observed growth under a cap, not a proof of nontermination; keyed deduplication on this fixture is not a weak-acyclicity result or a general polynomial-closure theorem.
