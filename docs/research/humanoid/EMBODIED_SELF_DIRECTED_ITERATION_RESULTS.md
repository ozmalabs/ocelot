# Embodied self-directed iteration

The developmental graph now treats re-instantiation as an embodied act. A
causally closed outcome is retained before any reset request is admissible.
The graph can request a new body after destruction, or voluntarily end an
unproductive experiment after a body-derived evidence window. Curiosity then
selects an interface-declared initial condition relevant to the active
developmental capability. The simulator only enacts the integer request and
returns a new situated observation.

No learned graph state is reset. Each enacted request advances an embodiment
generation, retains its causal request and receipt, and accounts for the
replacement cost. Reset availability and cost are observations and Pareto
tradeoffs, not safety permissions.
