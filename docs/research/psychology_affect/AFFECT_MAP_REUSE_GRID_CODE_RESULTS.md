## Exploratory arms (no thresholds)

**X-A4: hexagonal controls on the same machinery.** Six ControlResponses in axial
coordinates, laid out as dc = di and dr = dj, on a 25×25 open belief with a wall ring and
goals at the 120 S_hex points.

- Arrival: 120/120 within 64 steps.
- Steps = hex distance: 120/120. No walk revisited a cell.
- Over the 120 walks: A₆ = 0.0689166489056, matching the oracle. A₃, A₄, A₅, A₇ and A₈
  are all ≤ 7.3e-17.

The prereg flagged a possible tie between an axis control and a diagonal control under the
per-dimension sign vector. On this belief the Dot-pick tie-break never chose a
non-progressing move. The code is still a single scale, not a multi-module grid code
(prereg §7).

**X-B3: what `qdist` encodes on the experience map.**

- Decode of the 33-cell staircase belief: 7 passable quanta, 14 portals, 0 frontiers.
- Excess steps over Manhattan: 0 for 38 pairs, +2 for 4 pairs. The +2 pairs are
  happy↔afraid and happy↔angry in both directions (Manhattan 7, 9 steps). BFS on the
  same belief gives Manhattan for these pairs (prereg §4), so the extra steps come from the
  route rule. `qf_hop_route` minimises box hops (`qdist` + `cost`, 1 per portal), not cells.
- Spearman ρ between the start quantum's `qdist` and the anchors' distances, n = 42:
  - Euclidean: ρ = **0.558**.
  - Manhattan: ρ = **0.633**.

  Both are positive and below 1, which is the stated direction. One Manhattan distance maps
  to several `qdist` values: pairs at Manhattan 7 have `qdist` 0.0, 3.0 or 5.0, depending on
  whether they share a quantum.

## Reading (prereg §6)

- **G-A1–A3:** the spatial map has a 4-fold, not 6-fold, directional code. This is the
  expected baseline and the control the rung was designed around.
- **G-B1:** the map format is domain-general in fact. The same primitive and rules carried
  a valence–arousal lattice with no mechanism change.
- **G-B2:** in open space the reused map encodes reachability, not metric distance. The only
  distance information is the L1 step count from per-dimension pose arithmetic. So Ocelot as
  it stands predicts a **city-block** distance signal. Ma & Kragel's design could not
  separate city-block from Euclidean distance.
- **X-B3:** on a structured experience map, `qdist` carries distance only coarsely
  (ρ 0.56–0.63), and box-hop routing can cost extra steps (4/42 pairs, +2 each). Both depend
  on the greedy box decomposition.
- **X-A4:** a 6-fold code is available from the control set alone, with unchanged
  machinery. This is a candidate route to grid-like structure without a new primitive. It is
  one scale only and was not gated.
