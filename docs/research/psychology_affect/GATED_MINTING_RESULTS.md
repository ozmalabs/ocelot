# Gated Dimension-Minting (block 351000)

## What this closes

This is the closing facet of the arc "a train of thought is a trajectory through a
manifold". Blocks 348/349 steer the trajectory to stay inside a **tube** (a set-point) by
measuring its **deviation** — the residual `concept_signature` tuples the set-point never
admitted — and turning that integer residual into attention **width**. But the residual
itself was discarded each segment; only its `len()` survived, to steer the width.

Block 351 **keeps** the residual. When the *same* uncoverable structure **recurs** across
segments — a **persistent** residual — the manifold itself is too small: it has no
dimension for a thing the thinker keeps thinking. So it **coins one**. This is
**accommodation** (grow the space), not **gap-fill** (patch a single miss). Reframed in the
user's terms: the inner conversation keeps encountering a thought it has no axis for, and
once that recurs, it mints an axis for it.

## What is reused (honest naming — no minting machinery is invented here)

- **The decision is the seeded shape-decode loop's**, not Python's. `seeds/shape_decode_loop.json`
  via `reflective_faculty.induce_concern(agent, observation, *, name_hint=)` — hand it the
  persistent residual as a relation-system, the *rules* return:
  - `minted` → coin a `CapabilityAxis` from the residual;
  - `recognized` → a held codebook axis already covers it → **no mint** (the null);
  - `recognized_duplicate` → an induced axis with this same key already exists → **no mint**
    (the over-minting guard added specifically to stop unbounded axis growth).
  This block only *reads the verdict back*.
- **The residual** is block-349's aperture-grain residual `frozenset(traj) − admitted`,
  kept as a **set** instead of reduced to `len()`.
- **The width control law and the tube** are `regulated_train_of_thought`'s, unchanged.

## What is new (additive) — `domains/minting_train_of_thought.py`

`run_minting_train_of_thought(wa, *, setpoint_observer, ...)` runs the same aperture-grain
segment loop as the regulated train (the trajectory is generated by
`train_of_thought.run_inner_conversation` at the current integer attention_width, steered by
the integer aperture deviation), and additionally, each segment:

1. computes the residual **set** `frozenset(traj) − admitted`;
2. advances an integer **persistence ledger** (`residual_persistence: {predicate → int}`) by
   `+1` for every residual **predicate** present *this* segment — a predicate absent this
   segment does **not** advance, so a transient miss never accumulates;
3. once a predicate's persistence reaches the integer `mint_after_quanta` (and has not
   already been offered), hands the persistent predicate to `induce_concern`. The sd-loop
   decides; this block records the verdict in `mint_events` and the coined ids in
   `minted_axes`.

Everything is **discrete quanta**: persistence counts, `mint_after_quanta`, deviation, and
width are all integers; the residual tuples carry the integer step `k` from
`analogy_search._round_to_vocab`. No floats, no continuum. Teacher-free at loop time: the
persistence gate and the sd-loop are pure graph reads; no LLM decides anything.

`setpoint_observer` is **required** — the aperture-grain tube is the only tube over which a
signature *residual* (the mint surface) is defined; the concept-region tube (block 348) has
no signature residual to mint from.

| **G4** discrete quanta: every steering + gating quantity is an integer (deviation, width, persistence, thresholds) | PASS |
| **G5** teacher-free: ask-spy = 0 across every held-path run | PASS |

**Verdict (from the script):** the train of thought grows its own manifold — when a residual
signature (a thought with no held axis) recurs across segments (a persistent, integer-counted
residual), the seeded shape-decode loop coins a new `CapabilityAxis` for it; a single or
too-brief miss mints nothing (accommodation, not gap-fill); the over-minting guard refuses
duplicates; discrete quanta throughout; teacher-free; the regulated controller is unchanged.

## The seed (teacher-free, additive)

The block-349 demo graph: an is-a spine (poodle→dog→mammal→animal→organism, sparrow→bird→
animal) with distinct dynamical coordinates on each concept (`state` → `dynamical:valence`,
`identity_field` → `dynamical:commitment`) plus the qualia codebook (`seeds/shape_vocabulary.json`
+ `seeds/qualia_space.json`) so `concept_signature` is genuinely multi-axis and a residual
exists to mint from. A fine-grain set-point observer anchored on the neutral `animal`
concept gives a narrow tube the roaming trajectory keeps escaping — the persistent residual.
