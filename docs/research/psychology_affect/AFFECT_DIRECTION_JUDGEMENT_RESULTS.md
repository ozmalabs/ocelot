## Reading (prereg §6)

1. **Within-category valence direction is not represented.** Every distinct-level gain or
   loss pair is published with the same valence. The substrate already computes the
   graded quantity (`value_progress`, 32 to 512 in this sample) and then discards it at
   `em_readoff`, which keeps only its sign.
2. **Gains and losses are asymmetric.** Joy routes `value_progress` into `arousal`, so an
   observer reading both channels can order gains. Sadness falls through to
   `low_arousal` (50) at every loss size. Under the bound in G-3, a loss of 32 and a loss
   of 512 are indistinguishable in everything the read-off publishes.
3. **Mixed events are published inconsistently.** With joy and fear both firing,
   `emotion` says fear and `arousal` is the threat's 128, but `valence` is +1, because
   the rule gives +1 whenever any positive emotion fired.
4. **No direction judgement exists in the graph.** Read-offs are context-free (G-1), and
   no seed stores a previous valence or arousal (prereg §1.1). A rule cannot compare what
   the graph does not keep.

These results support a change to the affect read-off but do not make it. The candidate
change, stated for a successor prereg:
- publish a graded integer valence (for example `value_progress`, which is already
  in-frame and integer);
- give sadness an arousal from the loss magnitude;
- state an explicit valence policy for mixed events.

That successor must keep `tests/test_core_emotions_migrated.py` (the 11/11 emotion table)
green. It must also check every reader of `valence`, since several rules test only its
sign (for example `emx_fear` requires `valence < 0`). It should cover the
`ModulatorState` → `AffectiveState` path as well, which has the same sign quantisation
by inspection.

## Limits

- Path (B), `ModulatorState` → `AffectiveState`, was not run.
- The direction judgement is an offline ideal observer. The agent makes no such judgement.
- The events are hand-authored appraisal configurations, and the truth columns are
  declared (prereg §3).
- Only the harness's default parameters were used. Anger, frustration, disgust,
  curiosity, boredom and fulfilment are not in the sample (prereg §7).
- This was a single machine and a single engine build, with no independent reproduction.
