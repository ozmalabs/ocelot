# P3-R0 local readiness design

P3-R0 is a finite, preregistered local preflight for submitting a future P3-E1 package to an independent evaluator. It does not establish P3-E1 success, independent evaluator custody, learning adoption, continual learning, or general intelligence. It requires an externally signed P2 phase-go attestation, a complete signed P3 lock, and provisioned P0/P1 evidence before it can launch a worker. Missing/malformed/untrusted prerequisites create a sealed no-go/impasse.

The lock binds every control-plane artifact and the native export/candidate/pre-snapshot; workers see sealed next-only task envelopes, no private truth/seeds/order and no scores. The native data-plane model represents only rule/seed/codebook changes under `mutable-agent/`, validates direct/transitive forbidden references, computes byte snapshots/restores, and has no `approved` state. Only the evaluator can append sealed result-linked outcomes; R0 always rejects and restores.

Promotion requires a separately arranged independent evaluator, its own custody and release authorities, a verified lock and P2-go, P0/P1 provisioned containment evidence, sealed raw records, and exact rollback evidence. Same-user local Podman remains local qualification only.
