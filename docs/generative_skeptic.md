# The generative skeptic — GENERATE the probe, don't get given it

## VERDICT (lead)

The agent now GENERATES its own skeptical probes. The self-skeptic's EXECUTION half
(the `self_check_hat`) already fired a weighted check GIVEN a conclusion's
claimed/realised support + stakes + a weak-link do-contrast — but a human still
supplied WHICH thing to doubt. This builds the GENERATIVE / framing half: given a
RAW conclusion, the agent produces the probe ITSELF (which thing to doubt, where
the weak link is, what do-contrast reveals the miss), extracts the inputs the hat
needs, and feeds them in. **generate -> the hat fires.**

pgrep-verified COMPLETED) — for each RAW conclusion the agent generated the right
probe WITHOUT being given it, chained it to the hat, and got the right REOPEN:

## (1) Does it GENERATE the right probe for the 3 known cases WITHOUT being given it? — YES (3/3)

For each raw conclusion the agent **matched a failure-shape harvested from its own
banked lessons** and **transferred** the probe — none was handed in:

- **W5** → harvested `verdict_scored_against_a_moving_or_degraded_baseline` (from its
  banked W5 episode) → generated *"CHECK THE OLD/ANCHOR BASELINE: is this scored
  against a baseline that itself DEGRADED this run?"*, and read the hat-inputs off
  the conclusion's own numbers (claimed 0.625 = the anchor's prior, realised 0.20 =
  what it crashed to). The weak link it generated: *"anchor/baseline integrity."*
- **B-frontier** → harvested `high_compression_but_domain_irrelevant_frontier` →
  generated *"CHECK DOMAIN ADMISSIBILITY: is this in the domain or breadth junk?"*
  and **MEASURED** the realised support ITSELF — `domain_admissibility` scored the
  conclusion's tokens against the question's speech vocabulary = **0.000** (the
  "70B / GPU / QLoRA" axis has zero speech words). The realised number was
  generated by the skeptic, not handed in.
- **bad-ears** → harvested `hardware_or_knob_mistaken_for_a_capability_or_structure`
  → recognised the "X needed for Y" form and **ran the existence-proof
  counterexample over the agent's breadth**: `find_existence_proof` searched the
  agent's Concepts and found `human_robust_recognition_coarse_cochlea` — a system
  that achieves robust recognition WITHOUT the dense ear → X is a knob, realised
  support for "the knob is the lever" collapses to 0. **No numbers handed in at
  all** for this case; the whole input came from the agent's own knowledge.

## (2) Chained with the hat: do the generated probes → the right REOPEN/REJECT/COMMIT? — YES (3/3)

Each generated probe was fed straight into `self_check_hat.self_check`. The hat
fired (weights 0.533 / 0.874 / 0.874, all > the 0.30 threshold) and resolved
**REOPEN** for all three — rejecting the False "True", the breadth-junk frontier,
and the hardware-knob "lever". The execution half is unchanged and untouched; the
generative half feeds it. `generate -> the hat fires` is demonstrated end to end.

Honest cosmetic note: the hat's `resolve()` prints one phrasing — "compared to a
DEGRADED baseline" — for any realised-support collapse. For W5 that is literally
right; for the breadth-junk and existence-proof cases the *decision* (REOPEN) is
correct and the realised-collapse signal is the right one, but the printed *reason*
re-uses the W5 wording (the hat has only that one phrasing). The hat is a built /
frozen piece — not touched here. The generated probe text carries the correct,
case-specific reasoning.

## (3) The HONEST BOUNDARY — does taste reduce to the shape-library?

**Partly. The residual is real and named.** On a NOVEL off-distribution conclusion
("Dvorak reduces finger travel vs QWERTY") that exhibits NO banked failure-pattern,
the skeptic **bottoms out**: `generate_probe` returns `matched=False`,
`residual="novel_failure_no_matching_shape"`, and says so —
*"cannot synthesise a targeted probe for an un-banked failure-mode; bank the
episode (add a FailureLesson) to make it harvestable."*

So **taste reduces to (the harvested failure-shape library) + (the counterexample
search over breadth)** — but NOT to zero. A genuinely fresh failure-mode the agent
has never lived is a fresh-mind residual until it is BANKED, at which point it
becomes a harvestable shape and the residual shrinks. This is exactly the
order_n_postulates situation (its implication-shapes are harvested, but a postulate
with no donor shape derives nothing) — the dual of it. The skeptic does not force a
pass on the novel case; it reports the boundary. The mechanism for *closing* the
residual is built in (bank an episode → a new shape), but the act of recognising a
brand-new failure-mode for the first time is not itself harvested.

## (4) What was built (file:line)

A NEW module + a NEW seed + the killer replay. ADDITIVE — no core, no task-B files.

- **`domains/generative_skeptic.py`** — the generative skeptic, the DUAL of
  `order_n_postulates`:
  - `harvest_failure_shapes` (`:73`) — reads every graph-resident `FailureLesson`
    node and returns its failure-SHAPE `{match_patterns, probe_template, weak_link,
    hat_inputs, needs_for, lacks_thing}`. The dual of
    `order_n_postulates._shapes()` / `implication_harvester.harvest_shapes` — shapes
    harvested from the agent's banked lessons (graph data it owns), not a Python
    probe list.
  - `match_failure_shapes` (`:139`) — loose STRUCTURAL match of a raw conclusion's
    surface against the shapes' patterns (the same `re.search` loose match
    `order_n_postulates.differentiate` uses; the shape fires by surface form, the
    hat decides if the doubt holds).
  - `domain_admissibility` (`:155`) — MEASURES a conclusion's domain relevance (the
    breadth-junk shape's realised-support recipe) — generated, not handed in.
  - `find_existence_proof` (`:175`) — the COUNTEREXAMPLE / existence-proof
    generator: given "X needed for Y", a graph walk over the agent's breadth
    Concepts for a witness "Y holds WITHOUT X" (the bad-ears move).
  - `generate_probe` (`:227`) — THE GENERATIVE ACT: harvest → match → transfer the
    matched shape's probe + weak-link + hat-input recipe for THIS conclusion, run
    the counterexample/admissibility channels, and return a `GeneratedProbe`. On no
    match → the named residual.
  - `skeptic_check` (`:316`) — the full chain: generate the probe, then feed it to
    `self_check_hat.self_check`. **generate → the hat fires.**
- **`seeds/generative_skeptic.json`** — the agent's banked FAILURE-LESSONS as graph
  data: 6 real episodes it lived (W5 moving-baseline, 70B breadth-junk, bad-ears
  hardware-knob, consistency-mistaken-for-accuracy, boolean-over-the-numbers,
  premature-stop), each carrying the failure-shape harvested from it. These are
  recorded HISTORY, not a hand-authored probe list — the same status as the
  Concepts `order_n` harvests its implication-shapes from.
- **`scripts/generative_skeptic_replay.py`** — the killer test (world-adapter glue:
  translates the JSON lessons into `FailureLesson` nodes, installs one breadth
  Concept for the existence-proof, feeds the 3 known + 1 novel raw conclusions).
