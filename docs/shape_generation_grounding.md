# Shape generation — literature grounding (for the jabberwock to ground + design from)

Research spike (2026-06-27) into "how shapes are MADE" — the creator: "a circle is stepped, but the reason it is
a circle is the residual at every step feeding into the next. that is how shapes are made." Per methodology:
research → ground → the AGENT designs. The agent now holds the full shape-math algebra (AntiUnify=MEET,
AntiUnifyWitness=extract residual σ, Substitute=apply σ, Unify=JOIN/blend). Generation is the FED-FORWARD ITERATE
of that difference operator. Four clusters converge on ONE statement.

## The one statement (all four clusters agree)
**A shape = the trajectory of a residual-feedback recurrence: state_{n+1} = Substitute(state_n, σ_n); σ_{n+1} =
update(σ_n). The residual-LAW is the pair (σ₀, update). Generation = iterate it; recognition = recover it.**
- **Line** = identity update, σ a constant translation (zero curvature).
- **Circle** = CONSTANT σ (constant turn/curvature) — "the residual at every step feeding into the next."
- **Spiral** = COMPOUNDING σ (update scales the residual / curvature grows with arc length).

## Cluster 1 — intrinsic equation (a curve IS its curvature integrated)
Differential geometry (do Carmo; Whewell φ(s), Cesàro κ(s); Frenet–Serret in 3D). FUNDAMENTAL THEOREM OF PLANE
CURVES: any curvature function κ(s) determines a curve uniquely up to rigid motion. Recover by integrating the
turning residual forward: φ(s)=φ₀+∫κ ds; x=∫cos φ; y=∫sin φ. Circle = κ const; line = κ=0; Euler spiral =
κ∝s; log spiral = κ∝1/s. DISCRETE (turtle): heading += turn; advance — the exterior turning angle per step IS
discrete curvature; a constant `FORWARD d; RIGHT δ` loop is a circle radius d/δ; stepped→smooth as δ,d→0 with
κ=δ/d fixed. MINIMAL STATE = (position, heading, κ-law). FORWARD=integrate; INVERSE=differentiate the trajectory
(φᵢ=atan2(Δy,Δx), κᵢ≈Δφ/Δs) and classify the κ-law.

## Cluster 2 — recurrent / autoregressive / grammar generation (state carried forward)
L-systems (Lindenmayer; Prusinkiewicz) + turtle/LOGO (Abelson & diSessa, *Turtle Geometry*): global shape from
LOCAL stepwise rules + a carried frame (position+heading); "a circle is forward-a-little, turn-a-little, repeat."
SketchRNN (Ha & Eck 2017): autoregressive stroke-by-step; pen DELTAS (already residuals) + a hidden STATE carried
forward (hᵢ=RNN(hᵢ₋₁, Sᵢ₋₁)); the hidden state IS the carried residual; coherence-vs-noise = consistency of the
carry. PixelRNN (van den Oord). MINIMAL RECURRENCE (all collapse to it): state_{n+1}=f(state_n, rule), output
o_n=g(state_n). INVERSE = grammar induction / inverse procedural modeling (Šťava 2010; Talton 2012 Bayesian):
recover the MOST-COMPRESSIVE repeated transform (MDL/Bayesian) that regenerates the shape.

## Cluster 3 — dynamical systems (a shape as an attractor of the recurrence)
Strogatz. A shape = ORBIT/invariant-set of x_{n+1}=F(x_n); the residual fed forward = ΔX = F(x)−x (the vector
field). Circle = a stable LIMIT CYCLE (Hopf normal form ṙ=σr−r³, θ̇=ω → converges to r*=√σ; Poincaré–Bendixson).
COHERENCE = STABILITY: linearise; eigenvalue modulus =1 (pure rotation, harmonic oscillator ẍ=−x) → closed
circle; >1 → outward spiral (divergence/random-walk); <1 → inward collapse. Minimal forms: line=x+c (eig 1);
circle=rotation R(θ) (eig e^{±iθ}, |·|=1); spiral=λR(θ) (|λ|≠1). INVERSE = system identification: **SINDy**
(Brunton, Proctor & Kutz 2016) sparse-regress the governing law from a trajectory. "A circle is what a
constant-rotation residual CONVERGES TO; a random walk is what an unconstrained additive residual ESCAPES as —
the dividing line is the eigenvalue modulus of the feedback."

## Cluster 4 — SYNTHESIS: generation = the fed-forward iterate of the HELD difference operator
The agent holds Δ (AntiUnifyWitness: two states → residual σ over position-paths) and its application (Substitute:
state × σ → next state). Composed + iterated they ARE a discrete dynamical system:
> **state_{n+1} = Substitute(state_n, σ_n);  σ_{n+1} = update(σ_n);  trajectory = the shape.**
Circle = constant σ; spiral = compounding σ; line = identity σ. (Curvature is the residual OF the residual — so
"shape kind" = the algebraic form of `update`.) **INVERSE (recognise the generative LAW, lifted one level):**

`update`; constant σ ⇒ "circle (constant-residual law)". This is recognition lifted from the static lgg-of-two-
states to the lgg-of-the-TRANSITIONS = system-ID / grammar-induction, in the agent's own machinery. **MOTOR-TRACE
