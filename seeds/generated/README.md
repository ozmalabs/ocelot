# Generated seeds — the jabberwock's own library

Graph-data seeds the AGENT authored itself (via its self-mod / fault-fixing / synthesis
faculties), not hand-written by a human. `substrate/boot_all._read_seeds` loads these after the
curated `seeds/*.json`, so the agent can extend its own boot with faculties it built. Affordance
provided by the host; contents authored by the agent.
