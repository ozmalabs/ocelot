# Physics and analogy driven motor proposal mining

Jabberwock can use its whole cognitive loop to propose what to practise, not
merely choose among authored developmental steps. Most of the substrate is
already present:

- receipt-learned opaque-effector consequences and factorized
  analysis-by-synthesis in `gen_embodied_motor_program_seed.py`;
- verified multi-program trajectory search in
  `gen_embodied_program_trajectory_seed.py`;
- structural load/envelope constraints in the embodied structural-limit core;
- shape-matched, output-null motor hints and cross-morphology recall;
- metacognitive residuals, Pareto comparison, contextual negative memory, and
  curiosity-driven discrimination.

The missing component is a general-cognition bridge with this graph contract.

1. A `LearningPlanResidual` mints an `EmbodiedPhysicsQuestion`: what categorical
   body-state change would produce evidence for the unresolved capability?
   Desired consequences use the existing body-relative axes, support topology,
   energy, and load vocabulary—not joint names or poses.
2. Shape retrieval finds programs, transitions, hints, and other body plans
   whose precondition/consequence topology overlaps the question. These are
   analogical basin hints, never commands.
3. Existing analysis-by-synthesis composes arbitrary simultaneous effector
   programs and forward-projects their receipt-learned consequences. Structural
   envelope rules reject proposals beyond the currently inferred body limits.
4. Each surviving `MotorLearningProposal` publishes a complete integer Pareto
   point: predicted evidence, context discrimination, novelty, energy, load,
   and recoverability. No scalar reward or fixed retry count is introduced.
5. Curiosity collapses one incomparable proposal specifically to distinguish
   competing physics explanations. Only the existing single motor-decision
   collapse can grant temporary actuator authority.
6. The ordinary physical receipt closes the proposal. Prediction error updates
   the forward model; causal evidence promotes the proposal into a reusable
   program or meta-program; failure becomes contextual negative knowledge.
7. Repeated successful proposal shapes become warm-start hints shared by
   structurally similar body plans. They remain output-null until locally
   verified.

All cognitive quantities must be integer quanta. Simulator units and floating
point remain confined to transduction interfaces. The first implementation
should target the current rolling residual: ask which learned support,
orientation, momentum, and limb-coupling consequences can compose a half-turn,
then compare those synthesized experiments against the existing developmental
alternatives.
