## Physical assay

`results/humanoid_floor_mobility_v11.json` is the first full active assay. It
learned 98 developmental program transitions, retained 3,900 prefixes, reached
depth nine and selected one path. This establishes arbitrary-order path
construction in the physical loop. No path completed replay before the end of
the episode, and the body remained at developmental stage eight with the same
eight mastered capabilities as v8. Side-lying therefore remains unresolved.

The v11 body produced 28 support alternations and 0.0094 m directed progress.
Those are separate observations, not a collapsed success score. The run does
not support a claim that trajectory planning improved locomotion.

## Failures found by the assay

The first attempted live implementation copied every transition into every
situated profile and caused combinatorial growth. A later active attempt took
more than 17 minutes because generic expansion shared the broad
`cognitive_pareto` scheduling area and was swept during unrelated Pareto work.
Both runs were stopped and are not result artifacts.

The corrected architecture keeps one capability-owned transition inventory,
gives construction its own System 2 area, leaves dominance/selection in the
general Pareto area, and only expands the profile rooted at the current
program. After v11, total retained candidates were explicitly bounded and
duplicate System 2 escalation from the same receipt was removed. Dominated
prefixes deliberately remain extendable: a deterministic test caught that a
locally dominated intermediate can be the only route to a superior later
state. These final cost controls pass deterministic tests but have not been
claimed as a faster full physical run.

## Remaining developmental residual

The planner was initially starved because early developmental programs do not
satisfy the legacy gait transition learner's task-context assumptions. The
bridge now mints body-neutral edges directly from consecutive verified
developmental receipts. The remaining issue is not representational order: it
is useful state/program equivalence. Cold exploration synthesizes many exact
program identities, so a learned edge graph is only reusable when the existing
shape machinery recognizes a later current program as the same functional
basin. That equivalence/consolidation boundary is the next discriminative
target.
